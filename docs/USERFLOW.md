## 0. 페르소나
- **고객(주 사용자)**: 바이브코더·인디 메이커. 자기 제품/서비스를 마케팅하고 싶지만 콘텐츠 만들 시간 없음. "승인만 하면 되는" 자동화를 원함.
- **운영자(나)**: 전체 워크스페이스 관리·발행 엔진 운영.

## 1. 고객 핵심 유저플로우 (Happy Path)
```
가입(/login signup)
  → 이메일 인증(또는 Confirm OFF면 즉시)
  → 로그인 → 자기 워크스페이스 1개 자동 활성
  → [온보딩] 채널 연결(API 키 입력)         ← ※ 지금 버그였던 지점(연결 화면 안 뜨고 Queue로 빠짐)
  → 브랜드 설정(보이스 슬라이더 / 제품 repo / 톤 가이드)
  → "AI로 한 주치 초안 생성"(seed)
  → 승인 인박스에서 승인/거절(모바일 90초)
  → 자동 발행(cron) → 성과/캘린더 확인 → 반응 좋은 글이 다음 생성에 반영(자기개선)
```
**활성화(Aha) 기준**: 가입 후 5분 내 "내 브랜드 글이 큐에 쌓이고 1건 승인" 도달.

## 3. 채널 정책 (확정 필요 — 현재 불일치)
- 코드상 **구현 채널 16개**(threads·x·instagram·facebook·bluesky·telegram·discord·slack·line·tumblr·pinterest·linkedin·tiktok·youtube·naver_blog·midjourney), 각자 연결 폼 존재.
- 그런데 화면에선 일부만 노출돼 **"16개 미연결"과 실제 보이는 채널이 안 맞음**.
- **결정 필요**: 1차 정식 제공 채널을 무엇으로? (예: threads·x·instagram·facebook·linkedin·tiktok·youtube 7개만 노출, 나머지는 "준비중"). → 확정되면 배너 카운트·그리드·사이드바를 그 집합으로 통일.

## 4. 미해결 디자인/UX 결정 (확정 필요)
- **테마**: 라이트모드 기본 + 다크 선택(토글). 현재 전 화면 하드코딩 다크 → 테마 시스템 도입 필요(별도 작업, 큼).
- **로고**: 실 로고 파일 필요(현재 스레드 로고 제거 후 임시 "O" 마크). `public/logo.svg`로 교체 예정.
- **온보딩 순서**: 가입 직후 채널연결을 강제할지(위저드) vs 건너뛰기 허용.

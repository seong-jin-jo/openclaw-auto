# 회장 원문: OSMU 4실 실사용 피드백과 즉시 배포 요청

일단 배포된거 써보고 빠르게 해결해야할 문제점인데 일단 이번에는 QA 생략하거나 느슨하게 하더라도 일단 배포해서 내가 써볼수있게 해줘.

1. 문서에 따르면 첫 방문시 U2, U3 을 받아야 하는데 생성실에는 R6만 있는거지? 자세히 보니까 U2 U3 은 학습 정보 채우기에서 별도로 받는것 같은데, 고객들에게 6계층 필요한 정보를 다 잘 입력받고 있는거야? 필수적인것은 받고 에이전트가 벤치마킹과 창의성을 잘 살려야 하는데.
2. S0, S1, X4 는 관리자가 어떻게 세팅하고 X4는 고객이 언제 어떻게 선택해야하는거냐
3. L5 는 성과실에 존재는 하는거냐?

<생성실>
- 보니까 채팅에서 ‘학습 정보 채우기’ 누르니까 U2, U3 을 받고 있는 것 같은데 이걸 이렇게 위계 두는게 맞냐? 첫 화면에서 팝업이든 챗봇에서든 받고, 닫으면 헤더의 학습 정보를 잠깐 깜빡거리게 하던지 해서 여기서 채울 수 있다고 안내하는 식이 낫지 않겠냐? 왜 헤더에 학습 정보가 사라짐? 그리고 이렇게 만드는게 ‘브랜드 가이드’ 맞아?
- 우리 목표가 프롬프팅이나 하네스 엔지니어링없이 백지공포 기술공포 없이 클릭 클릭으로 컨텐츠를 만들어 관리하는 에이전트라는게 핵심인데 R6 정보도, 학습정보에서 받는 U2 U3 정보도 주관식이면 나라도 뭘 입력해야할 지를 모르겠는데
- ‘오늘 만들 수 있는 것’ 은 뭐하는 예시이지? 추천 영상이야? 전혀 모르겠어. 만들 수 있는게 저 3종류밖에 있는게 아닌데.
- 지금 이 폴더에서 영상 카드뉴스 등 실험중인데 카드뉴스에서는 브랜딩 인아웃트로, 후킹, CTA 같은거 고민중이고 카드뉴스에 메인 사진, 본문, 클로징 사진 등 있는데 이런걸 후보군에서 고르면서 이런 결로 만들고 싶다 결정해야하지 않을까 싶어 하나의 제안이야. 벤치마킹 잘 해봐. 
- 또 힉스필드에서 실험중인 데이터가 있을텐데 처음 고객들은 seedance, cling, wan3 등 모델이 뭐가뭔지도 모르고 뭘써야할지도 모르잖아 이게 생성이나 편집에서 편하게 잘 써볼수있게 고민해야해
- 만들 종류는 글/카드뉴스/영상 중복 선택 가능하게 해야하는거 아니냐? 하나의 주제로 OSMU 하고 싶을 수도 있잖아
- 소재 권리를 확인했습니다는 뭐지?
- 챗봇 UI에서 주제 목적 대상 (언어, 원하는 결과 이런거 빠졌네 계층별 정보 정의는 되었냐?)만 받고 바로 후보를 만들어? 더 물어볼 것 없어? 물어볼때 스텝바이스텝이 더 UX 상 좋지 않을까
- 혹은 그냥 AI가 추천하는 영상으로 바로 후보보기 하는 것도 있으면 좋을것같고 시그마인처럼 최소의 정보만 던지면 AI 모델이 창의적으로 만들어서 대충 나올수있게

<편집실>
- 목차가 가려져서 파탄났음
- 편집실에서는 챗봇을 통해 어떻게 편집하지? 챗봇만의 UX 장점이 있어야 쓰는거아님?
- 올릴 플랫폼을 선택해서 규격에 맞게 미리보기 하면서 편집해야하지 않을까? OSMU도 되어야하고. 지금은 들어가자마자 영상이고 카드뉴스 글을 챗봇에서 선택해서 편집하는 UX가 이상한데
- 컨텐츠가 미리볼 수 있는게 없는데 내가 어떻게 확인하냐 넌 QA는 어떻게 했어?

- 왜 여긴 챗봇 없어? 일부러 없게한건가? 생각해보면 생성편집실은 챗봇이 어울려보이는데 발행실은 기타 메타정보를 관리해서 미리보는게 목적일거같고… 챗봇 있으면 좋을까
- 왜 X만 글은 내용이 다르고 닉네임은 화면밖으로 나가버렸고

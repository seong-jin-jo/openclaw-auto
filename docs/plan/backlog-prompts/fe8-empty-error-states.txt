빈 상태와 오류 상태를 전 화면에서 정리한다.

지금은 데이터가 없거나 요청이 실패했을 때 화면마다 다르게 군다. 어떤 곳은 빈 칸만 남고, 어떤 곳은 영문 오류가 그대로 나온다.

할 일:
1. 주요 화면 전부를 데이터 0건 상태로 열어 무엇이 보이는지 관찰한다. 홈, 생성실, 편집실, 발행실, 성과실, 채널, 설정.
2. 요청이 실패했을 때 무엇이 보이는지 관찰한다. 네트워크 끊김, 401, 500 을 실제로 만들어 본다.
3. 빈 상태에는 다음에 무엇을 하면 되는지를 둔다. 사족 설명이 아니라 할 일 하나.
4. 오류에는 사용자가 할 수 있는 것을 둔다. 영문 오류 원문을 그대로 노출하지 마라.
5. 화면마다 다르게 굴지 않게 공통 컴포넌트로 모은다.

관찰한 것과 고친 것을 표로 남겨라. 캡처는 docs/prototype/qa-fe8/ 에.

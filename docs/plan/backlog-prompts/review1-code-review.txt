특히 공격할 것:
1. **돈**: 무료 재생성 몫이 우회 가능한가. 동시 요청 두 개가 같은 몫을 두 번 쓸 수 있는가. 시간대를 바꾸면 몫이 초기화되는가. 멱등 키를 재사용하면 무슨 일이 나는가.
2. **격리**: A 작업 공간 토큰으로 B 의 것에 닿는 경로가 하나라도 있는가. 새 API 가 tenant 검사를 빠뜨렸는가. RLS 가 실제로 걸렸는가, 아니면 애플리케이션 코드에만 있는가.
3. **동시성**: 숏폼 여덟 개가 같은 자원을 두고 다투는가. 한 컨셉 실패가 나머지를 죽이는가. 편집 계약의 revision 충돌 처리가 실제로 원자적인가.
4. **거짓 성공**: 실패했는데 성공으로 보고하는 경로. 부분 실패를 전체 성공으로 세는 곳.
5. **사유 없는 삭제**: 밤사이 지워진 기능이나 테스트가 있는가. 있으면 왜 지웠는지 커밋 메시지에 근거가 있는가.
6. **확정 요구 이탈**: 사족 문구, 긴 대시, 이모지, 영문 단추 라벨이 새로 들어왔는가.

생성실과 편집실을 확정 시안대로 실제 앱에 붙인다.

발행실과 성과실은 이미 붙였다. 남은 두 방이다.

회장이 이미 확정한 것(요구 대장에서 확인하고 그대로 따를 것):
- 왼쪽 사이드바는 로그가 아니라 유저 흐름이다. 네 방이 상시 보인다
- 생성은 기본적으로 챗봇에서 고른다. 디스플레이에 텍스트와 단추를 주르륵 늘어놓지 마라
- 각 단계의 설명이나 예시가 디스플레이에 있어야 한다. 화면에서 뽑은 근거를 써 놓지 마라
- 영상, 카드뉴스, 글, 음악 선택은 디스플레이에 두지 말고 헤더나 적절한 곳에 상태판을 둔다
- 편집실에서 대사는 항상 아래에 뜬다. 영상 목차는 왼쪽에 둔다
- 편집 도구는 VREW 와 CapCut 을 벤치마킹해라. 실제로 조사하고 무엇을 가져왔는지 근거를 대라

# 유저플로우 · v58

## 1. 주 흐름 (dead-end 0)

```
비회원 로그인
  └ 학습 정보 0건?
      ├ 예 → 생성실(첫 손님) : 왼쪽 예시 · 오른쪽 0 / 9
      │        └ 대화창이 여쭙는다 ─┬ 회원님 얘기부터  → U2 6가지 채움
      │                             ├ 작업 공간부터    → U3 3가지 채움
      │                             └ 예시부터 볼래요  → 예시 유지, 값은 그대로 0
      │        └ 9 / 9 채워지면 같은 화면이 실제 후보 셋으로 바뀐다
      └ 아니오 → 생성실(정상) : 후보 셋 A · B · C
                  └ 대화창 "어느 화면으로" → 후보 고르기
                       └ 대화창 "어느 결로" → 완성 확인
                            └ 대화창 "편집실로 넘길까요" → 편집실
편집실 : 목차에서 고치고 대사로 자른다
  ├ 받아 가기 → studio 단독 손님 출구(만료 링크 · 자산은 계속 보관)
  └ 발행실로 넘기기
발행실 : 갈래 묶음에서 칸을 눌러 플랫폼별 설정 → Publish (N)
  ├ 미연결 채널 → 사이드바가 가리키는 그 채널 화면 Settings 탭에서 연결
  ├ 일부 실패 → 채널별 딱지에 사유 · 다시 연결하고 재발행
  ├ 승인 인박스에 보관
  └ 캘린더로 예약
성과실 : ① 답할 것 → ② 무엇이 통했나 → ③ 기록
  └ 규칙 후보 승낙 → 학습 정보 L5 에 쌓임 → 다음 생성이 읽는다  (고리가 닫힌다)
```

## 2. 이 판에서 바뀐 경로

| 경로 | v57 | v58 | 근거 |
|---|---|---|---|
| 방 이동 | 사이드바 네 방 + 개수 | 사이드바 네 방 + **순번·지금·다음** | R176 |
| 후보 고르기 | 디스플레이 카드를 눌러 고름 | **대화창에서 A / B / C** | R177 |
| 근거 확인 | 생성실 맨 위 근거 판 | **학습 정보 화면 한눈에 탭** | R178 |
| 갈래 바꾸기 | 편집실 디스플레이 탭 | 헤더 상태판이 알리고 **대화창에서 바꿈** | R180 |
| 지난 것 다시 꺼내기 | 발행실 오른쪽 기록 레일 | **헤더 작업물 전체** 하나로 | R183 |
| 플랫폼 문구 손보기 | 드로어에 문구·해시태그 둘 | 드로어에 **제목·이름·캡션·해시태그·첫 댓글** | R184 |
| 댓글에 답하기 | 발행실 댓글 관리 탭 | **성과실 답할 것 탭** | R185 |

## 3. 갈래별 상태 (happy 아닌 경로)

| 지점 | 갈래 | 화면이 하는 말 | 막다른 길인가 |
|---|---|---|---|
| 첫 손님이 값을 안 주고 싶다 | 예시부터 보기 | 예시 셋은 그대로 보이고 대화창이 "회원님 것이 아니다"를 말한다 | 아니오. 언제든 대화창에서 값 채우기로 돌아온다 |
| 후보 셋이 다 마음에 안 든다 | 셋 다 아니에요 | 담당이 어떤 쪽이 마음에 안 드셨는지 한 줄을 청한다 | 아니오 |
| 편집 중 갈래를 바꾸고 싶다 | 갈래 바꾸기 | 헤더 상태판이 지금 갈래를 말하고 담당이 바꿔 준다 | 아니오 |
| 무음 구간이 없다 | 줄이기 단추 비활성 | `무음 없음` 이라고 적힌다 | 아니오 |
| 발행할 채널이 하나도 연결 안 됐다 | 미연결 띠 | 첫 미연결 채널 이름으로 `Instagram 연결하러 가기 →` | 아니오. 그 채널 화면 Settings 로 간다 |
| 일부 채널만 실패 | 채널별 딱지 | 실패 채널에 `연결이 만료됐습니다` | 아니오. 재연결 후 재발행 |
| 플랫폼에 제목 칸이 없다 | 없다고 적음 | `Threads 는 제목 칸이 없습니다. 첫 줄이 제목 노릇을 합니다` | 아니오 |
| 답할 댓글이 영업 문의다 | 보류 | 초안을 안 만들고 `보류`로 둔다 | 아니오 |
| 성과 표본이 모자란다 | 근거 얇음 | `근거가 아직 얇습니다` 를 후보 옆에 적는다 | 아니오. 승낙은 사람이 정한다 |
| 지표 연동이 안 됐다 | 연동 전 | 0 으로 세지 않고 `연동 전`으로 둔다 | 아니오 |
| studio 만 쓰고 발행 안 한다 | 받아 가기 | 만료 링크 넷 + `구독을 그만두셔도 지우지 않습니다` | 아니오. 자산 보존 |

## 4. 아직 안 그린 상태 (다음 판 몫 · 숨기지 않고 적는다)

1. **편집실 컷 0개.** 대사를 전부 빼면 무엇이 보여야 하는지 안 그렸다.
2. **성과실 댓글 0건.** 아직 아무 반응이 없는 첫 주에 이 방이 무엇을 말해야 하는지 안 그렸다.

이 둘은 화면이 없으면 막다른 길이 된다. 다음 판에서 먼저 그린다.

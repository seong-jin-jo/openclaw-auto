## 1. 주 경로 (happy path)

```
[GNB] 작업 공간 선택
   │
   ▼
1번 방 생성 ──▶ 2번 방 편집 ──▶ 3번 방 발행 ──▶ 4번 방 성과
   │                │                │               │
   │                │                │               └─▶ 둘러보다 만들기 ──┐
   │                │                │                   (맥락 이관)      │
   │                │                └─▶ 인박스 보관 / 캘린더 예약        │
   │                └─▶ 되돌리기 ──▶ 1번 방(맥락 배너)                    │
   └◀───────────────────────────────────────────────────────────────────┘
```

클릭 수: 제안 클릭 → 후보 클릭 → 편집 확인 → 발행 선택지 클릭. **최소 4회로 발행까지 도달.**

## 2. 단계별 경로 전수

### 2.1 진입

| 경로 | 도착 | 상태 |
|---|---|---|
| 사이드바 방 클릭 | 그 방 | 정상 |
| GNB 내 작업물 → 항목 열기 | 그 작업물이 **지금 있는 방** | 정상 |
| GNB 알림 → 승인 대기 | 3번 방 인박스 | 정상 |
| GNB 알림 → 연결 만료 | 설정 채널 연결 | 오류 |
| GNB 알림 → 발행 결과 | 4번 방 | 정상 |
| 사이드바 채널 클릭 | 그 채널 연구실(`/channels/[ch]`) | 정상 / 권한 필요 |
| 사이드바 키워드 4항목 | 키워드 화면 해당 탭 | 정상 |
| 사이드바 자산 3항목 | 자산 화면 해당 탭 | 정상 / empty |

### 2.2 1번 방 생성

| 분기 | 다음 | 막다른 길 방지 |
|---|---|---|
| 제안 3장 중 하나 클릭 | 지침 확정 → 후보 만들기 | — |
| 제안이 다 마음에 안 듦 | 직접 쓰기(보조 경로) | 주 경로가 아님을 화면이 먼저 밝힘 |
| 학습 정보 0인 첫 사용자 | 업종 기준 제안이 즉시 깔림 | 백지 없음. 학습 입력은 관문이 아님 |
| 후보 생성 중 | loading. 화면 닫아도 계속되고 알림 옴 | 기다림 강제 없음 |
| 후보 0개 | empty. 다시 만들기 + 소요 시간 명시 | 방치 없음 |
| 브랜드 기준 위반으로 중단 | error. 비용 미차감 명시 + 고치러 가기 / 그대로 다시 | 두 문 모두 열림 |
| 후보 셋 중 선택 | 2번 방으로 | 나머지 둘은 보존, 나중 완성 시 추가 과금 명시 |

### 2.3 2번 방 편집

| 분기 | 다음 | 비용 |
|---|---|---|
| 자막 문구·크기·속도·순서 변경 | 즉시 반영. 다음 단계 열림 | 무료 |
| 이미지·목소리 교체 | 즉시 반영 | 컷당 크레딧(누르기 전에 라벨로 표시) |
| 발행실로 보내기 전에 미리보기 | 3번 방 | — |
| 1번 방으로 되돌리기 | 1번 방 + **맥락 배너**(어디서·어디로·들고 온 값·원본 보존) | 원본 안 지워짐. 앞 방 목록에 항목 +1 |
| 아무것도 안 바꿈 | empty 안내("오른쪽 값을 하나 눌러 보시면") | 방치 없음 |

### 2.4 3번 방 발행

| 분기 | 다음 | 실패 처리 |
|---|---|---|
| 플랫폼 탭 전환 | 그 플랫폼 실물 미리보기 | — |
| 캡션·해시태그·첫 댓글 수정 | 왼쪽 미리보기 즉시 반영 | 상속분과 변경분 분리 저장 |
| 공통 초안으로 되돌리기 | 채널 변경분만 폐기 | 공통 초안은 남음 |
| 지금 발행하기 | 발행 결과 | 막힌 채널은 나머지만 올라가고 초안 보존 |
| 승인 인박스에 보관하기 | 인박스 depth | 되돌린 항목도 목록에 남음 |
| 캘린더로 예약하기 | 캘린더 depth | 승인 전에는 예약 안 잡힘(노란 대기) |
| 시간 위임 | 제안 시각 + 근거 + 표본 한계 | 승인 게이트가 통제감 유지 |
| 연결 안 된 채널 | 권한 필요 상태. 이유 + 담당(내가/우리가) | 초안 보존 명시 |

### 2.5 4번 방 성과

| 분기 | 다음 | 비고 |
|---|---|---|
| 글 옆 답글 달기 | 그 글의 미답변 답글 | 판단 버튼이 대상 옆 |
| 글 옆 내려서 보관 | 보관 확인 | 자동 삭제 안 함 |
| 글 옆 비슷하게 만들기 | 1번 방 + 맥락 배너 | 발행물은 되돌릴 수 없음 |
| 키워드 클릭 | 그 키워드의 실물 후보 카드 | 근거 라벨(우리 로그 / 공개 사례 / 가설) |
| 후보 카드 → 생성에 보내기 | 1번 방 + 맥락 배너 + 작업물 목록 +1 | 원본 손대지 않음 |
| 성과 없음(첫 로그인) | empty. 남의 성과를 둘러보다 만들기로 첫 행동 | 0을 지어내지 않음 |
| 값 수집 실패 | **미수집** 표기 | 0으로 세지 않음 |

---

## 3. 되돌리기 규약 (회장 확정 5번)

1. **덮어쓰지 않는다.** 되돌리면 앞 방의 작업 목록에 항목이 **새로 하나 생긴다.** 원본은 그 자리에 남는다.
2. **맥락을 들고 간다.** 도착 화면 맨 위에 배너가 붙고 네 칸을 답한다: 어디서 / 어디로 / 들고 온 맥락 / 원본은 어떻게 됐나.
3. **초기 화면으로 보내지 않는다.** 되돌린 지침이 이미 선택된 상태로 도착하고 "되돌린 내용 그대로 이어서 하기" 버튼이 같은 자리에 있다.
4. **성과에서는 되돌아갈 수 없다.** 이미 나갔기 때문이다. 대신 맥락만 들고 1번 방으로 새로 간다.

---

## 4. 상태 전수 (dead-end 0)

| 상태 | 어디에 | 그 화면이 답하는 것 |
|---|---|---|
| 정상 | 전 화면 | — |
| 내용 없음(empty) | 성과 첫 로그인 · 후보 0 · 편집 미변경 · 작업물 0 · 학습 0 | 무엇이 생기면 채워지나 + 지금 할 행동 1개 |
| 불러오는 중 | 후보 생성 · 성과 수집 | 얼마나 걸리나 + 떠나도 되나 |
| 오류 | 브랜드 기준 위반 · 토큰 만료 · 발행 일부 실패 | 원인 + 보존 여부 + 다음 행동 |
| 일부 완료 | 채널별 성과 정의 불일치 | 왜 합치지 않나 |
| 권한 필요 | 미연결·오픈 준비중 채널 | 내가 풀 것인가 우리가 풀 것인가 |
| 결과 확인 중 | 외부 발행 결과 미확인 | 중복 발행하지 않음 |
| 기록 복구 | 외부 성공 / 내부 기록 실패 | 재발행 금지, 기록만 복구 |
| 과다(overflow) | 작업물 8건 · 7열 표 · 장문 제목 · 채널 11종 | 격자가 안 터진다(스크롤·clamp·칸수 축소) |

**막다른 화면 0건.** 모든 오류·차단 화면에 되돌아갈 문 또는 다음 행동이 최소 하나 있다.

---

## 5. 근거 표시 규약 (회장 지적 3번)

세 가지만 쓰고, **색이 아니라 이름으로** 구분한다. 뜻은 담당 레일 머리에 상주하는 범례가 항상 밝힌다.

| 라벨 | 뜻 | 시각 |
|---|---|---|
| 우리 실험 로그 | 우리 계정에서 직접 돌려 본 결과. 표본과 기간이 함께 적힘 | 실선 테두리 |
| 공개 사례 | 바깥에서 관찰한 남의 결과. 우리 계정 검증 전 | 파선 테두리 |
| 가설 | 근거 부족. 검증 지표와 기간을 함께 적음 | 점선 테두리 |

---

## 6. 학습 정보 (회장 확정 3·4번)

- 공통 정보가 상위, 워크스페이스가 그 안. 아래가 위를 덮어쓴다.
- 취향은 두 갈래다: **창작 취향**(주제·말투·금지선)과 **운영 취향**(댓글 말투·발행 시각 판단).
- 발행 쪽에도 학습된 취향이 있다. "네가 적절한 시간 골라서 발행해"가 성립하려면 운영 취향이 있어야 한다.
- 작업 공간을 바꾸면 학습 정보의 맨 윗층이 통째로 바뀐다는 것을 GNB 전환 패널이 그 자리에서 알린다.

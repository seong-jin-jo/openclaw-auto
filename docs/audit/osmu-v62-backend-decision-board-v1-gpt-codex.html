v62 백엔드 결정

댓글, 성과 제안, 학습 이력의 저장 경계를 정합니다. 추천안을 맨 위에 두었습니다.

현재 build는 차단 상태입니다. design과 eng-design 승인 전에는 이 선택을 소스나 DB에 반영하지 않습니다.

1. 댓글 첫 build 저장 방식

댓글 본문 읽기와 답글을 실제 provider로 먼저 검증할지 정합니다.

2. 댓글 장기 저장 구조

나중 처리, 답글 이력, inbox까지 제품 범위에 넣을지 정합니다.

3. 성과 제안 첫 build 저장 방식

성과실의 제안을 생성실로 넘길 때 새 저장소를 만들지 정합니다.

4. 성과 제안 장기 lifecycle

제안 노출, 수락, 제작, 결과 성과를 KPI로 추적할지 정합니다.

5. 학습 후보 승인 이력

R98의 표본 문턱과 R168의 수락 행위를 재현 가능한 기록으로 남길지 정합니다.

|---|---|

| 패널이 화면마다 실제로 바뀌는지 | 고유 화면 ID 27개 확인 |

증거 캡처(우측 패널 포함 전체 레이아웃): `panel-j01-1024.png` `panel-l00-1024.png` `panel-d02-1024.png` `panel-m01-768.png`

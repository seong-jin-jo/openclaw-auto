## 3. 리테이크 (design-review로 잡아 고친 뒤 재측정)

1. **수치 필드 라벨이 명암비 4.40 대 1로 AA 미달.** 새로 만든 `.factline` 라벨에 한 단 옅은 토큰을 썼다. 신규 색을 만들지 않고 한 단 진한 기존 토큰으로 옮겨 7.0 대 1이 됐다.
2. **플랫폼 미리보기 카드 본문이 검은 카드 위에서 2.72 대 1.** 앱 본문 규칙(`.panel p`)이 미리보기 카드 안까지 먹어 회색 글자가 검은 카드에 얹혔다. 미리보기 카드는 그 플랫폼의 실제 색을 흉내내는 자리라 카드 색을 그대로 물려받게 했다.
3. **패널 밖 제목이 22.5px로 글자 크기 7단을 벗어남.** 브라우저 기본값이 먹고 있었다. 20px 단으로 고정했다. 신규 크기 0.
4. **1440에서 해설 패널이 아래로 떨어짐(회장 지적 4).** 여백을 줄이는 방식으로는 1440 프레임을 감당할 수 없어 축소 방식으로 바꿨다.
5. **진행 표시의 큰 제목이 바로 아래 질문 제목과 겹쳐 한 화면에 제목이 둘이었다.** 진행 표시는 맥락이지 질문이 아니므로 제목을 뺐다.

### 남은 두 건은 결함이 아니라 측정 한계

플랫폼 미리보기 안 두 곳(인스타그램 슬라이드, 영상 자막)은 배경이 그라디언트라 자동 대비 계산이 배경색을 못 읽고 흰 글자를 밝은 배경 위로 오판한다. 실제로는 남색 그라디언트와 영상 위의 흰 글자다. 캡처로 육안 확인했다.

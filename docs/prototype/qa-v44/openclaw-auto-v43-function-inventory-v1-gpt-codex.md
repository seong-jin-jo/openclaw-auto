## 2. 공통 기능 잠금

| 기능 | v43 상태 | v44 처리 |
|---|---|---|
| 헤더 | 작업 공간·작업물·학습 정보·크레딧·알림·계정 가로 정렬 | 그대로 보존. 학습 정보는 크레딧 바로 왼쪽 |
| 네 방 | 생성·편집·발행·성과와 단계별 작업물 서랍 | 그대로 보존. 흐름 장면에서 같은 네 방을 한 작업물의 이동축으로 연결 |
| 디스플레이 | 발표형 한 화면, 정상·내용 없음·불러오는 중·오류·내용 많음 | 그대로 보존. `한 편의 흐름`을 첫 장면으로 추가 |
| 담당 | 기본 접힘, 오른쪽 아래 56px 원형 호출 단추 | 그대로 보존 |
| 작업 공간 | 별도 브랜드 칸 없음. 공간마다 학습 정보와 취향 분리 | 그대로 보존 |
| 학습 정보 | 일곱 층, 스킬은 층, 규칙 승낙과 재검사 | 그대로 보존. 성과가 규칙 후보로 돌아오는 화면 연결 추가 |
| 처음 시작 | 채널 연결 없이 갈래부터 고름 | 그대로 보존. 생성실 흐름의 읽는 정보에 반영 |
| 채널별 문구 | 편집실에서 작성 | 그대로 보존. 편집실이 쌓는 정보로 표시 |
| 채널 연결 | 발행 시점 | 그대로 보존. 발행실이 읽고 쌓는 정보로 표시 |
| 15종 채널 | Threads, X, Instagram, Facebook, Bluesky, LinkedIn, Pinterest, Tumblr, Telegram, Discord, Slack, LINE, YouTube Shorts, TikTok, Naver Blog | 전량 보존 |
| 라이트·다크 | 양쪽 테마 | 그대로 보존 |
| 폭 | 390·768·1024·1440 검수 셸 | 그대로 보존. v44 핵심 흐름은 390·1024·1440 실렌더 추가 |

## 3. v44에서 더하는 것

| 추가 | 화면 수 | 기존 기능에 미치는 영향 |
|---|---:|---|
| 생성·편집·발행·성과·다음 생성 흐름 | 5 | 기존 방 화면은 건드리지 않고 디스플레이 장면만 추가 |
| 1440 다크, 390 라이트·다크 | 3 | 기존 반응형과 테마 토큰 재사용 |
| 불러오는 중·내용 없음·오류·내용 많음 | 4 | 기존 다섯 상태 계약을 흐름 장면에도 적용 |
| 합계 | **12** | v44 화면 정의 **131개** |

삭제된 기존 기능: 없음.

확정 지시로 v43 이전에 이미 제거된 항목인 별도 브랜드 칸, `내 에이전시`, 반복 가리킴 목록은 복원하지 않는다.

## 4. 셀프심문과 레드팀

이 인벤토리가 틀렸다면 가장 그럴듯한 이유는 SCREENS 밖의 공통 조작을 화면 수만으로 놓치는 것이다. 그래서 화면 수 외에 헤더·단계 서랍·담당·작업 공간·학습 정보·15종 채널·상태·폭·테마를 별도 잠금표로 두었다.

까다로운 기존 사용자는 새 흐름 때문에 익숙한 방과 채널 화면이 사라졌다고 공격할 수 있다. v44는 v43 파일을 통째로 복사한 뒤 SCREENS 앞에 12개만 추가하고, 회귀 스크립트로 이전 요소 생존을 다시 검사한다.

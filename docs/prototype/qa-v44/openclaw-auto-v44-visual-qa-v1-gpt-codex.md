## 6. 수정 루프

1차 390 캡처에서 학습 고리의 가운데 `규칙 후보`가 연결선에 밀려 약하게 보였다. 모바일은 선과 설명만 접고 뜻말 세 칸은 `repeat(3,minmax(0,1fr))`로 보존하도록 고쳤다.

브라우저 검사에서 v43 검수 대응표가 내부 이스케이프 함수를 전역처럼 부르는 콘솔 오류 1건을 찾았다. v43 파일은 보존하고 v44 검수 셸에 범위가 분명한 이스케이프 함수를 추가했다. 최종 재검은 콘솔 오류 0이다.

## 7. 레드팀과 셀프심문

까다로운 고객은 네 방과 두 데이터 묶음이 제품보다 내부 운영판처럼 보인다고 공격한다. 최종 화면은 기술 이름을 제거하고 `지금 읽음 / 이번에 쌓임 / 다음으로 넘김`으로만 설명하며, 현재 방 상세 외에는 레일로 축약했다.

이 판정이 틀렸다면 가장 그럴듯한 이유는 전체 검수 셸 캡처에서 제품 프레임이 축소돼 작은 글자의 실제 읽기 어려움을 놓치는 것이다. DOM은 실제 390·1024·1440 폭으로 레이아웃됐고, 390 라이트·다크 원본 캡처를 확대해 학습 고리 세 칸과 정보 칩의 줄깨짐을 직접 확인했다.

# 정보를 세 번에 나눠 받는다

**한 번에 다 받으면 지친다.** 그래서 세 시점으로 나눈다.

| 시점 | 무엇을 받나 | 어디에 쌓이나 |
|---|---|---|
| 1. 작업 공간을 만들 때 | 바로 답할 수 있는 것. 클릭으로 | 공통 정보 |
| 2. 만들려고 할 때 | 이번 콘텐츠의 결. 추천을 곁들여 | 생성·편집 정보 |
| 3. **첫 콘텐츠가 나온 뒤** | 올리고 운영하는 방식 | 발행·운영 정보 |

---

## 1. 작업 공간을 만들 때 (공통 정보)

바로 답할 수 있는 것만 클릭으로 받는다.

| 무엇 | 어떻게 |
|---|---|
| 콘텐츠를 만드는 목적 | 고르기 |
| 어떤 종류를 만들 것인가 | 글, 이미지, 숏폼, 음악 등에서 고르기 |
| 마케팅이라면 업종 | 고르기 |
| 타깃 | 고르기. 없으면 **질문으로 만들어 간다** |
| 사업 규모 | 고르기 |
| 목표 | 고르기 |
| 톤 | 고르기. 없으면 질문으로 |
| 발행 채널은 어디를 생각하나 | 고르기 |
| **이미 채널이 있나** | 있으면 **그 채널을 분석해 톤에 맞는 콘텐츠를 이어 만든다** |

**없으면 묻는다.** 빈칸으로 두지 않고 질문을 통해 만들어 간다.

---

## 2. 만들려고 할 때 (생성과 편집 정보)

이 자리에서는 **추천이 함께 들어간다.**

| 무엇 | 추천이 어떻게 붙나 |
|---|---|
| 어떤 느낌으로 하고 싶은가 | |
| 벤치마킹 중인 사이트나 콘텐츠가 있나 | **없으면 추천해 준다** |
| 길이는 어느 정도로 | **목적에 맞춰 추천.** 수익화라면 1분 이상이어야 한다, 경쟁사는 이 정도 길이로 간다 같은 근거를 함께 |
| 실사 느낌인가 캐릭터 느낌인가 | 목적에 맞는 것을 보고 추천 |
| 경쾌한가 진중한가 | 목적에 맞는 것을 보고 추천 |

**추천에는 근거가 붙는다.** 이 목적이면 보통 이렇게 한다, 경쟁사는 이렇게 하고 있다.

---

## 3. 첫 콘텐츠가 나온 뒤 (발행과 운영 정보)

**콘텐츠를 만들고 나서 처음 받는다.** 한 번에 다 받으면 지치기 때문이다.

| 무엇 | 내용 |
|---|---|
| 발행 시각 | 일정한 시각이나 주기로 할 것인가, 흩어서 할 것인가 |
| 좋아요 | 자동으로 할 것인가. 한다면 어떤 기준으로 |
| 댓글 | 어느 쪽에 어떤 결로 달 것인가 |

이렇게 정한 것이 학습 정보로 올라간다.

---

## 4. 학습 정보 화면

| 무엇 | 어떻게 |
|---|---|
| 언제든 볼 수 있다 | 사용자가 아무 때나 열어 본다 |
| **갱신되면 눈에 띄게 한다** | 바뀐 것이 있으면 화면에서 표시해 확인하게 만든다 |
| 무엇이 들어 있나 | 공통 정보, 생성과 편집 정보, 발행과 예약 정보, **사용자가 남긴 메모와 기록** |
| **챗봇으로 고칠 수 있다** | 말로 시켜서 학습 정보만 바꾼다 |

---

## 5. 챗봇이 먼저 제안한다

**기다리지 않고 먼저 말을 건다.**

| 무엇 | 왜 |
|---|---|
| 성과와 트렌드를 근거로 이런 콘텐츠 어떠냐고 먼저 제안 | 만들고 싶어져서 쓰게 만든다 |
| **알림을 준다** | 제안이 생기면 알려야 본다 |

이것이 백지 공포를 없애는 마지막 조각이다. 사용자가 무엇을 만들지 고민하는 자리를 아예 없앤다.

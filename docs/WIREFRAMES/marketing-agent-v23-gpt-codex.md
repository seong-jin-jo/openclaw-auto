## 0. 진단 브리프 (화면을 그리기 전)

**이 화면에 도착한 사람의 심리.** OSMU Studio에 온 사람은 한 번에 7개 채널로 나가는 글을 쓴다.
그가 두려워하는 것은 "내가 못 본 상태로 내 이름을 걸고 나가는 것"이다. 원하는 것은 문장 편집기가 아니라
**나가기 전에 내 눈으로 확인하는 창**이다. v22는 그 창을 없애고 창을 여는 버튼만 10개 늘어놓았다.
그래서 화면이 "선택지를 못 정한 상태"로 보였다.

**경쟁 UI 근거.** Hootsuite의 캡션 미리보기 도구는 플랫폼별로 다른 자름 규칙과 글자 상한을 각각 명시하고,
Instagram 캡션 상한 2,200자와 피드에서 접히는 구간을 구분해 보여준다. 동시에 그 문서는
자름 지점이 앱 버전·기기 폭·이미지 유무로 달라진다고 스스로 밝힌다
(https://www.hootsuite.com/social-media-tools/social-media-caption-preview).
차용한 것: 플랫폼별 프레임 + 플랫폼별 상한 표기.
버린 것: 자름 지점 숫자를 단정하는 것. 우리 정책 문서의 `[미확인]` 값과 같은 이유로 그리지 않았다.

**이번 판이 이기는 지점.** 미리보기가 별도 창이 아니라 편집하는 자리 옆에 상주한다.
고치면 그 자리에서 바뀐 모습이 보인다. 창을 열고 닫는 왕복이 없다.

| 2 | 영상 모델 select | 실제 코드가 `canGenerate`(운영자)에서만 노출한다. 이 프로토타입의 기본 시야는 고객이다. |

| 5 | 크레딧 표시·사용 이력 | 운영자 전용(`canGenerate`). 고객 화면 범위 밖. |
| 6 | 계정 선택 select | 이번 판의 시나리오는 채널당 계정 1개(@monostudio)다. 다계정은 실제 코드가 2개 이상일 때만 노출하므로 이 시나리오에서 코드도 안 그린다. |

| 8 | 드로어 리사이즈 핸들 | 정적 프로토타입에서 드래그 크기 조절은 재현 가치가 낮다. |
| 9 | 비주얼 프롬프트·이미지 재생성 | 운영자 전용 생성 기능. |
| 10 | TikTok 원본 사운드 줄 | 프레임 하단 캡션 2줄과 겹쳐 390px에서 글자가 눌린다. 넘침 규칙에 걸려 뺐다. |
| 11 | 실제 이미지·영상 미디어 | 프로토타입에 저작권이 확인된 실자산이 없다. 회색 자리표시 대신 실제 문구 장면을 넣었다(placeholder 금지 규칙). |
| 12 | 무료 이벤트 배너 | 한시적 이벤트 문구다. 지금 정책이 유효한지 확인되지 않아 확정 사실로 그리지 않았다. |
| 13 | 짧음·해시태그 없음·이미지 필요 3경고 | 미리보기 프레임에 붙일 자리를 아직 정하지 않았다. 카운터 옆에 붙이면 헤더가 4요소가 된다. 다음 판 대상. **갭으로 명시.** |
| 14 | 클립 텍스트 변형 3개 생성 | 영상 화면의 기능이고 이번 판 범위는 Studio 미리보기 복원이었다. |

누락 14건 중 결정이 필요한 것은 7번과 13번이다. 나머지는 운영자 전용 또는 정책·자산 사유다.

### S-STUDIO-1 · 묶음 안의 미리보기 블록

```
[실제 화면에 보일 모습]        글자수는 채널 공식 한도 기준입니다.

◎ Threads                              53/500  ← 프레임 헤더. 카운터는 오른쪽 끝
┌─────────────────────────────┐
│ ●  monostudio  1시간            ⋯ │
│    확인 가능한 마케팅 흐름을 먼저   │
│    만듭니다. 무엇을 왜 게시했는지  │
│    남겨야 다음 판단이 쉬워집니다.  │
│    ♡  ⌾  ↻  ➤                     │
│    답글 18개 · 좋아요 124개         │
└─────────────────────────────┘
[Threads 게시 전 확인]
프레임 안의 반응 수와 시간은 실제 코드의 예시 값입니다. 발행 뒤 실제 값으로 바뀝니다.
```

- 요소: 탭 행 / 프레임 헤더(로고·라벨·카운터) / 프레임 / 조치 1개 / 각주
- 상태: 정상·한도 초과(카운터 붉게)·한도 없음(영상)·카드 0장·계정 권한 확인 필요
- 인터랙션: 탭 전환은 프레임만 교체한다. 캐러셀 좌우는 카드만 바꾼다. 페이지 이동 없음.
- 심리 설계: 손실 회피. "나가기 전에 내 눈으로 본다"는 감각을 조치 버튼 앞에 둔다.
  게시 전 확인은 미리보기를 본 다음에만 눈에 들어오는 자리에 있다.

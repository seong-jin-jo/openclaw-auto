# 디스플레이 v43 와이어프레임

## 1. 1024·1440 기본 상태

주축은 `column`이다. `GNB → 네 단계 → 보조 툴바 → 디스플레이` 순서를 바꾸지 않는다. 디스플레이 카드 영역만 `row` 3열이다.

```text
┌ 작업 공간 모노스튜디오 · 맥락 ───── 작업물 ─── 학습 정보 ─ 크레딧 ─ 알림 ─ 계정 ┐
├ 생성 ───────────── 편집 ───────────── 발행 ───────────── 성과 ────────────────┤
├ 현재 캠페인                                      보는 사람 [고객]       테마 ┤
├ [추천] [예시] [편집 중] [자세한 설명]                                      ┤
│ ┌ 후보 카드 전체 선택 ┐ ┌ 선택 카드 전체 선택 ┐ ┌ 후보 카드 전체 선택 ┐     │
│ │                  ⛶ │ │                  ⛶ │ │                  ⛶ │     │
│ │ 보여 줄 결과물       │ │ 보여 줄 결과물       │ │ 보여 줄 결과물       │     │
│ └────────────────────┘ └────────────────────┘ └────────────────────┘  ◯담당 │
└───────────────────────────────────────────────────────────────────────────┘
```

- 학습 정보는 크레딧 바로 왼쪽이며 별도 줄로 내려가지 않는다.
- 기본 상태는 담당 접힘이다. 56px 원형 단추를 누르면 336px 패널이 같은 구석에서 열린다.
- 패널은 떠 있는 보조층이다. 열려도 카드 열수와 디스플레이 폭은 바뀌지 않는다.
- 카드 전체를 누르면 선택된다. 확대는 오른쪽 위 44px 아이콘이다. 문장형 보조 단추는 없다.

## 2. 390 기본 상태

주축은 계속 `column`이다. 카드 세 장을 세로로 쌓지 않고 `후보 1·2·3 탭 → 선택 카드 한 장`으로 교체한다.

```text
┌ 모노스튜디오 ─ 학습 정보 ─ 12,400 ┐
├ 생성 ─ 편집 ─ 발행 ─ 성과          ┤
├ 메뉴   보는 사람 [고객]       테마  ┤
├ 추천 · 예시 · 편집 중 · 자세한 설명 ┤
├ 후보 1 │ 후보 2 │ 후보 3            ┤
│ ┌ 선택 카드 전체                  ┐ │
│ │ 결과물                       ⛶ │ │
│ └───────────────────────────────┘◯│
└───────────────────────────────────┘
```

## 3. 상태와 상호작용

| 상태 | 보여 주는 것 | 다음 행동 | 막다른 길 |
|---|---|---|---|
| 정상 | 추천·예시·편집 결과 3개 또는 모바일 1개 | 카드 선택, 확대, 담당 열기 | 0 |
| 내용 없음 | 결과가 없는 이유와 작업 공간·주제 두 진입 | 작업 공간 선택 또는 주제 말하기 | 0 |
| 불러오는 중 | 카드 자리 3개와 읽는 대상 한 줄 | 기다리거나 담당 열기 | 0 |
| 오류 | 보존된 것, 다시 불러오기, 담당 우회 | 다시 불러오기 또는 주제 말하기 | 0 |
| 내용 많음 | 전체 수, 상위 3개, 남은 수 | 다음 장으로 이동 | 0 |
| 담당 펼침 | 대화 기록, 고르는 선택지, 직접 입력 | 선택·입력·접기 | 0 |

## 4. 기능 보존과 확정 제거

- 네 방, 채널 15종, 고객·운영자 전환, 라이트·다크, 모든 이전 상태와 라우팅을 보존한다.
- `내 에이전시`, 되짚어 보기, 말이 가리킨 곳 목록은 확정 지시로 제거한다.
- 별도 브랜드 칸과 디스플레이 브랜드 줄을 제거한다. 브랜드가 다르면 작업 공간을 추가한다.
- 스킬은 층계 안에 둔다.

## 5. 레드팀과 셀프심문

**까다로운 고객 공격:** 담당을 접으면 도움을 잃어버린 것처럼 보일 수 있다. 수정은 대비가 분명한 원형 호출 단추, 44px 이상 접촉면, 접근 가능한 이름을 같은 구석에 유지하는 것이다.

**이 결론이 틀렸다면 가장 그럴듯한 이유:** 떠 있는 패널이 결과물을 가릴 수 있다. 패널을 기본 접힘으로 두고 열어도 격자를 재배치하지 않으며 언제든 같은 자리에서 접게 해 위험을 줄였다.

# 화면 정의 · v58 · 디스플레이는 고르는 자리가 아니다

## 0. 이 판을 관통하는 원리 (R177)

> 회장 원문: "그냥 챗봇 UI 에서 선택을 하되 디스플레이에선 유저만의 정보가 쌓이는 느낌이 들게 하면 되지 않을까? 각 스텝에 대한 설명이나 예시가 디스플레이 있어야지, 디스플레이에 설명이나 선택을 하게끔 하지말라니까"

디스플레이가 하는 일은 둘뿐이다. **① 그 단계의 설명과 예시 ② 회원 고유의 정보가 쌓이는 느낌.**
고르는 것은 전부 오른쪽 대화창이다. 여섯 번째 지적이라 요구 번호를 하나씩 처리하지 않고 네 방을 이 원리로 다시 그렸다.

**적용 경계 (해석 · 회장 미확인).** "무엇을 만들지 고르는 선택"은 전부 대화창으로 보냈다. "이미 정해진 결과물을 다듬는 손"은 방에 남겼다. R181·R182 가 편집 조작을 화면 요소로 직접 지정하셨기 때문이다.

## 1. 셸 · 사이드바 (R176)

| 요소 | 상태 | 내용 |
|---|---|---|
| 묶음 라벨 | 상시 | `한 편의 제작 순서` |
| 진행 요약 | 상시 | `지금 2 / 4 · 다음은 발행실` / 방 밖이면 `아직 시작 전입니다. 생성실부터 시작합니다` |
| 방 항목 × 4 | 지나옴 / 지금 / 다음 / 아직 | 순번 칩(지나온 방은 `✓`) + 방 이름 + 배지(`지금 여기` / `다음`) |
| 연결선 | 상시 | 방과 방을 잇는 2px 세로선. 지나온 구간과 지금 구간만 강조색 |
| 채널 목록 | 상시 | 이 묶음 **아래**. 눌러서 그 채널 화면으로 가고 Settings 탭이 연결 자리(R175) |

**뺀 것.** 방마다 붙던 작업물 개수. 그것이 회장이 말씀하신 log 다. 개수를 보고 꺼내는 일은 헤더 `작업물 전체`가 갖는다.
**접힌 레일(1024).** 아이콘 자리를 순번이 차지하므로 접어도 순서가 읽힌다. 배지와 진행 요약만 숨는다.

## 2. 생성실 (R177 · R178 · R179 · R180)

디스플레이는 항상 두 칸이다. 단계가 바뀌어도 골격이 안 바뀐다.

### 2.1 왼쪽 · 이 단계의 설명과 예시

| 단계 | 제목 | 왼쪽에 서는 것 |
|---|---|---|
| 1 · 값 미수집 | 회원님을 알아가는 중 | `이 단계를 지나면 이런 것이 나옵니다` + **예시** 카드 셋(예시라고 적힘) |
| 2 · 화면 고르기 | 오늘 만들 수 있는 것 | `회원님께 받은 값으로 뽑았습니다` + 실제 후보 셋. 카드에 **A · B · C** 이름 |
| 3 · 후보 고르기 | 같은 화면의 다른 각도 | 저해상도 후보 셋 |
| 4 · 완성 확인 | 완성본 | 완성 화면 + 고른 값 목록 |

### 2.2 오른쪽 · 회원께 쌓인 것

- `3 / 9` 큰 숫자 + 채워짐 막대
- 층별 묶음: 회원님에 대해(U2 6개) · 이 작업 공간에 대해(U3 3개) · 성과에서 배운 규칙(L5)
- 채워진 칩은 **받은 값 자체**를 적고, 아직인 칩은 **무엇을 여쭐지**를 점선으로 적는다
- 발밑 한 줄: 근거는 헤더의 학습 정보에서 층별로 본다

### 2.3 고르는 자리 = 대화창

| 단계 | 담당이 먼저 여쭙는 말 | 선택지 |
|---|---|---|
| 값 미수집 | 먼저 회원님 얘기부터 여쭐까요 | 네 저부터 / 작업 공간부터 / 예시부터 보고 싶어요 |
| 화면 고르기 | 어느 화면으로 갈까요 | A / B / C / 셋 다 아니에요 |
| 후보 고르기 | 어느 결로 갈까요 | 첫째 / 둘째 / 셋째 / 다시 뽑아 주세요 |
| 완성 확인 | 이대로 편집실로 넘길까요 | 넘겨 주세요 / 후보 다시 / 갈래 바꾸기 |

### 2.4 상태

| 상태 | 화면 |
|---|---|
| 첫 손님(0 / 9) | 예시 셋 + 쌓인 것 0. 채우기 단추 없음 |
| 예시 보기 중 | 예시 셋 그대로. 대화창이 "회원님 것이 아니다"를 말함 |
| 값 다 받음(9 / 9) | 실제 후보 셋 + 쌓인 것 가득 |
| 390 | 두 칸이 세로로 쌓임(예시 위 · 쌓인 것 아래). 예시 카드도 세로 한 장씩 |

### 2.5 뺀 것

- `basisReceipt()` 층별 근거 판 → 학습 정보 화면 `한눈에` 탭 맨 위로 이관 (R178)
- 온보딩 종료 시 진행 멘트 `setFlash` → 담당 대화로 (R179)
- 갈래 선택 → 헤더 상태판 (R180). 상태판은 **생성실·편집실에서만** 뜬다

## 3. 편집실 (R181 · R182)

```
┌ 갈래 탭 (영상 · 카드뉴스 · 음악) ──────────────────────────────┐
│ ┌ 목차 214px ┐ ┌ 재생기 / 카드 / 파형 ──────────────────────┐ │
│ │ 1 훅        │ │                                            │ │
│ │ 2 전개      │ │                                            │ │
│ │ 3 결말      │ └────────────────────────────────────────────┘ │
│ └─────────────┘ ┌ 아이콘 조작 띠 ────────────────────────────┐ │
│                 │ ▭ 9:16   ◍ 차분한 남성 유료   ▶ 1배  ▤ 보통 │ │
│                 └────────────────────────────────────────────┘ │
│ ┌ 대사 (항상 아래 전체 폭) ──────────────────────────────────┐ │
│ │ 훅  0.0-4.2  3주 붙잡은 기능을 오늘 지웠습니다      [빼기] │ │
│ └────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

| 갈래 | 왼쪽 목차 | 아이콘 조작 | 아래 대사 |
|---|---|---|---|
| 영상 | 컷 목록(썸네일·번호·구간 초) | 비율 · 목소리(유료) · 속도 · 자막 크기 | 대사 다섯 줄. 빼면 그 구간이 잘리고 길이가 줄어듦. 무음 줄이기 단추 |
| 카드뉴스 | 장 목록 | 비율 · 글자 크기 · 배경 이미지(유료) | 장 문구 네 줄. 지금 장만 입력 가능 |
| 음악 | 곡 목록 | 목소리(유료) · 배경음악 · 볼륨 | 나레이션 대사. 무음 구간 표시 |

**아이콘 규칙.** 아이콘 하나 = 조작 하나. 옆에 **지금 값**을 적는다(접었다고 상태를 숨기지 않는다). 누르면 그 자리 아래 작은 판이 열리고 값만 고른다. **한 번에 하나만 열린다.** 유료 조작에는 `유료` 딱지.

**뺀 것.** 제목 붙은 큰 조작 칸 여섯. 값을 펼치면 결과물이 그만큼 줄어든다.

## 4. 발행실 (R183 · R184)

탭 넷: **올라갈 모습 · 올리기 · 승인 인박스 · 발행 캘린더**. (댓글 관리 탭은 성과실로 갔다 · R185)

### 4.1 올라갈 모습

| 위에서 아래로 | 내용 |
|---|---|
| 미연결 띠 | 0개면 안 보임. 누르면 **그 채널 화면**으로(R175) |
| 작업 줄 | 글감 이름 · N곳 선택 · 저장 · `Publish (N)` · 예약 |
| 발행 진행 | 백분율 · 막대 · 채널별 딱지 · 성공 채널 게시물 링크 · 중지 |
| 갈래 묶음 셋 | ✍️ 텍스트(Threads · X · Facebook) / 🎬 영상 9:16(Shorts · Reels · TikTok) / 🖼️ 카드뉴스(Instagram). 묶음 **안에서만** 옆으로 민다 |

### 4.2 칸을 누르면 열리는 드로어 = 플랫폼별 발행 설정 (R184)

| 칸 | 플랫폼별 |
|---|---|
| 제목 | Shorts · TikTok 만 있음(100자). 나머지는 **없다고 적고 왜 없는지 한 줄** |
| 표시 이름 | 전 플랫폼 |
| 캡션 | 한도를 칸 머리에 적음. Threads 500 · X 280 · Instagram 2,200 · Facebook 63,206 · Shorts 5,000 |
| 해시태그 | 전 플랫폼 |
| 첫 댓글 | 전 플랫폼. 해시태그를 내리면 본문이 짧아 보임 |
| 발밑 한 줄 | 달린 댓글에 답하는 것은 성과실에서 합니다 |

드로어 아래에 큰 미리보기. **한 번에 하나만 연다.** Esc 로 닫힌다.

### 4.3 뺀 것 · 올린 기록 (R183)

정본 `app/studio/page.tsx:566~580` 에 있으나 **이 화면엔 불필요**로 판정했다.
판단 근거: 지난 것을 다시 꺼내는 행동은 지금 올릴 것을 만드는 중에 일어나지 않는다. 232px 레일을 세우면 1024 에서 칸 하나가 잘린다. 그 일은 헤더 `작업물 전체`가 이미 갖는다(R153).

## 5. 성과실 (R185 · R186)

탭 셋. **회원이 이 방에서 실제로 하는 일 순서**다.

### 5.1 답할 것 (기본 탭)

```
┌ 필터 172px ┐ ┌ 댓글 스트림 ──────────────────────────┐
│ 전체   5   │ │ T @yeonjae.dev  Threads · 12분 전  답할 것 │
│ 답할 것 3  │ │ │ 올린 글 · 3주 붙잡은 기능을 오늘 지웠습니다 │
│ 고칠 것 1  │ │ 저도 두 달 붙잡은 기능 지웠습니다...        │
│ 보류   1   │ │ ┌ 답글 · 경험 공유 ─────────────────┐    │
│ ──────     │ │ │ (초안이 미리 채워져 있음)          │    │
│ Threads 2  │ │ └───────────────────────────────────┘    │
│ Instagram 1│ │ [이 답글 보내기] [좋아요] [나중에]        │
└────────────┘ └───────────────────────────────────────┘
┌ 담당이 대신 하는 것 (아래 전체 폭) ────────────────────┐
│ 자동 좋아요 켜짐 / 자동 답글 초안까지 / 영업 문의 꺼짐  │
└────────────────────────────────────────────────────────┘
```

- 댓글마다 **어느 글에 달린 것인지**를 위에 적는다. 맥락 없이 말만 있으면 무슨 얘기인지 알 수 없다.
- 답글 칸은 **고른 하나만** 연다. 넷을 다 열면 입력 칸 넷이 한 화면에 선다.
- 수정 요청 댓글에는 `편집실에서 고치기` 단추가 붙어 방을 넘긴다.
- 실데이터 다섯: 경험 공유 · 수정 요청 · 질문 · 영업 문의 · **반박**. 좋은 말만 있는 화면은 실제와 다르다.
- 390: 필터가 가로 스크롤 알약 줄로 접힌다.

### 5.2 무엇이 통했나

글 **셋**만 본다. `가장 멀리 간 글` · `가장 오래 붙든 글` · `기대보다 못 간 글`.
각 카드 = 머리(구분 · 채널) + 제목 + 지표 3칸 격자(조회 · 저장 · 답글) + **왜 그런지 한 문장**.
그 아래가 v55 자산인 **배운 규칙 승낙 루프**(`l5Panel`). 승낙한 것만 다음 생성이 읽는다.

### 5.3 기록

정본 `app/page.tsx` 계승분. 요약 지표 넷(증감 붙임) · 지금 도는 것(draft / approved / published / performing) · 발행물 표 일곱 열 · 확인할 것 · 사용량.
값이 없는 칸은 0 으로 세지 않고 `연동 전`으로 둔다.

## 6. 상태 분기 · dead-end 점검

| 화면 | empty | 정상 | 과다 | error / 미달 |
|---|---|---|---|---|
| 생성실 | 0 / 9 첫 손님 게이트 | 9 / 9 후보 셋 | 후보 C가 장문(카드가 안 터지는지 상시 확인) | 값 미수집 상태에서 예시 보기 |
| 편집실 | **미달.** 컷 0개 상태 미작성 → 다음 판 | 컷 3 · 대사 5 | 대사 다섯 줄 스크롤 | 무음 없음일 때 단추 비활성 |
| 발행실 | 미연결 0개면 띠가 사라짐 | 갈래 셋 · 칸 일곱 | 옆으로 밀어 더 보기 | 일부 발행 실패 → 채널별 딱지에 사유 |
| 성과실 | **미달.** 댓글 0건 상태 미작성 → 다음 판 | 댓글 5 · 필터 넷 | 보류 포함 전체 5 | 연동 전 값은 0 으로 안 셈 |

**미달 2건은 숨기지 않고 적는다.** 편집실 컷 0개, 성과실 댓글 0건. 다음 판 몫이다.

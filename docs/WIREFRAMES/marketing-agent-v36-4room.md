## 0. 이 판이 왜 이렇게 만들어졌나

v32~v35는 33KB 백지에서 다시 쌓은 계보다. 그 대가로 v18~v31까지 13판에 걸쳐 만든 자산이 사라졌다.
실측: 해시태그 v24=2건 → v35=0건, Instagram 캐러셀 v24=1건 → v35=0건, 플랫폼×형식 대조표 소멸.

v36은 새로 그리지 않았다. v31 파일을 복사하고 그 위에 방 네 개를 얹었다.
v35에서 가져온 것은 넷뿐이다. 앱 사이드바 25항목, 헤더 GNB, 기기 프레임과 화면 연번, 4실 구조와 그 사이 이동.

## 1. 셸 · 모든 방이 공유하는 뼈대

```
main-axis = column
┌──────────────────────────────────────────────────────────────┐
│ 헤더 GNB (min-height 56)                                      │  ← 작업 공간 전환 · 내 작업물 N · 크레딧 · 알림 · 계정
├──────────────────────────────────────────────────────────────┤
│ GNB 패널 (펼쳤을 때만, 헤더 아래로 밀고 들어옴. 화면을 안 덮음)  │
├────────────┬────────────────────────────────┬────────────────┤
│ 사이드바    │ 본문 (minmax(0,1fr))            │ 담당 레일 320   │
│ 224px      │  main-axis = column             │  (접힘 48)      │
│            │  격자 = repeat(12,minmax(0,1fr))│  sticky top:16  │
└────────────┴────────────────────────────────┴────────────────┘
```

- **본문 영역 주축 = row**, `grid-template-columns: minmax(0,1fr) auto`. 719px 미만에서 column.
- 담당 레일은 **떠 있는 말풍선이 아니라 열**이다. 어느 방에서도 오른쪽 끝 같은 열, 같은 상단 좌표(실측 `fromRight:11 / fromTop:99` 네 방 동일).
- 프레임 1440에서만 기본 펼침. 그보다 좁으면 접힌 세로 탭으로 시작한다. 좁은 폭에서 펼치면 본문이 400px대로 눌려 미리보기 카드가 터진다(실측 확인).

### 사이드바 25항목

| 묶음 | 항목 |
|---|---|
| 제작 studio | 방 2개 (생성 · 편집) |
| 운영 openclaw | 방 2개 (발행 · 성과) |
| Social posts | Threads · X (Twitter) · Instagram · Facebook · Bluesky |
| Messaging | Telegram · Discord · Slack |
| Social short video | YouTube Shorts · TikTok |
| Custom Integration | Blog |
| Data and Analytics | Blog Performance |
| Keyword Research | Keyword Planner · Search Console · Naver Trends · Google Trends |
| Assets and Tools | Images · Videos · Midjourney |
| System | 학습 정보 · Settings |

- 방 4 + 채널 11 + 데이터 1 + 키워드 4 + 자산 3 + 학습 1 + 설정 1 = **25**.
- 채널 줄에는 연결 상태를 함께 적는다: 연결됨 / 미연결 / 오픈 준비중 / 확인 필요. 미연결(고객이 누르면 됨)과 오픈 준비중(우리가 끝내야 함)을 합치지 않는다.
- 채널 자료구조 정본은 `dashboard/src/components/layout/Sidebar.tsx`. 프로토타입은 `CHANNELS` 배열에서 사이드바를 만든다(손으로 다시 적지 않는다).
- v31의 `/`·`/studio`·`/inbox`·`/calendar`는 사이드바에서 방으로 대체됐지만 라우팅과 흐름 색인에는 그대로 산다(`LEGACY_DEST`). 화면을 지운 것이 아니라 소속을 옮겼다.

## 2. 1번 방 · 생성 (studio-service)

### 요소

| 영역 | 내용 | 상태 |
|---|---|---|
| 방 머리 | 방 이름 + 네 방 진행(1/4 강조) + 소유 서비스 + 여기 걸린 작업물 수 + 이름 후보 안내 | 고정 |
| 오늘의 제안 | **추천 카드 3장.** 근거 라벨 + 실제 나갈 문구 + 형식·비용·소요 + 주 행동 | 정상 / empty(첫 사용자는 업종 기준 제안) |
| 옵션 | 말투 알약 3개. 파선 묶음, 근거 없음 | 정상 |
| 확정된 창작 지침 | 제안을 고른 뒤에만. 주제·말투·금지선·출력 언어 각각 출처 표기 | 제안 미선택 시 "직접 쓰기"로 대체 |
| 후보 3개 | v31 `candidatePanel()` 그대로. 저해상도 3안 + 선택 도장 + 비용 | loading / empty / error |
| 담당 레일 | 제작 담당. 근거 범례 상주 + 칩 3개 + 직접 입력 | 접힘/펼침 |

### 추천과 옵션을 다르게 그리는 규칙 (회장 지적 12)

| | 추천(제안) | 옵션 |
|---|---|---|
| 부품 | `.reco-card` | `.opt-pill` |
| 테두리 | 실선 2px, 고르면 강조색 | 파선 묶음 + 얇은 알약 |
| 근거 | 근거 라벨 필수 | 없음 |
| 실물 | 실제 나갈 문구를 인용 블록으로 | 없음 |
| 값 | 형식·비용·소요 3개 | 없음 |
| 행동 | primary 버튼 | 토글만 |

### 인터랙션

- 제안 카드 클릭 → 지침 패널이 그 자리에서 채워진다.
- 칩 클릭 → 대화가 한 단계 진행되고 사용자 발화가 레일에 쌓인다.
- 성과실에서 "이걸로 생성에 보내기"로 도착하면 되돌리기 배너가 맨 위에 붙는다.

## 3. 2번 방 · 편집 (studio-service)

**창작 없음.** 여섯 조작이 전부이고, 전부 실제로 눌리고 왼쪽 미리보기가 그 자리에서 바뀐다.

| 조작 | 부품 | 즉시 바뀌는 것 | 과금 |
|---|---|---|---|
| 자막 문구 | 입력 | 미리보기 자막 글자 | 무료 |
| 자막 크기 | 세그먼트 3택 | 자막 font-size (15/20/27px) | 무료 |
| 재생 속도 | 세그먼트 4택 | 길이 초 표시 + 재생바 폭 | 무료 |
| 첫 컷 이미지 | 세그먼트 3택 | 미리보기 배경 + 장면 라벨 | 컷당 |
| 나레이션 목소리 | 세그먼트 3택 | 메타 줄 + 톤 설명 | 컷당 |
| 컷 순서 | 위로/아래로 | 순서 목록 실제 재배열 | 무료 |

- 바꾼 것은 아래 "방금 바꾼 것"에 **무료 / 크레딧 차감**으로 갈라 쌓인다.
- 되돌리기: 앞 방 목록에 항목이 하나 늘고 원본은 남는다. 도착 화면에 맥락 배너가 붙는다.
- 상태: 정상 / 아직 아무것도 안 바꾼 empty / overflow(자막 장문에서도 자막이 2줄 이상으로 흐르되 프레임을 안 넘김).

## 4. 3번 방 · 발행 (openclaw-service)

하위 depth 3개: **미리보기 · 승인 인박스 · 발행 캘린더**.

### 미리보기 depth

- 플랫폼 탭 7개: Threads · X · Instagram · Facebook · Shorts · Reels · TikTok.
- 각 탭은 v31 `pvFrame()`의 실물 목업이다.
  - Threads: 아바타 + 이름 + 1시간 + 본문 + 좋아요/댓글/재게시/보내기 + "답글 18개 · 좋아요 124개"
  - X: 확인됨 뱃지 + @핸들 + 본문 + 답글 24 / 재게시 57 / 좋아요 312
  - Instagram: 카드뉴스 5장 캐러셀(좌우 화살표 + 1/5 + 점 표시) + 좋아요 1,284개 + 캡션 + 해시태그 줄
  - Facebook: 전체 공개 + 본문 + 좋아요 248 · 댓글 32 · 공유 12 + 하단 3탭
  - Shorts / Reels / TikTok: 세로 영상 + 안전 영역 표기 + 12.4K / 318 / 공유(또는 저장 1.2K) + 캡션
- 오른쪽 편집칸: 캡션(글자수 한도 표시) · 해시태그 · 첫 댓글 · 영상이면 화면 자막.
- 아래: **플랫폼×형식 대조표 8행**(플랫폼 / 형식 / 현재 사실 / OSMU에서 / 플랫폼에서) + **채널별 다시 쓰기** 안내(YouTube · TikTok · Pinterest 중복 정책 + 8개 채널 같은 문장 경고).

### 발행 선택지 (회장 지정 문구 그대로)

1. **지금 발행하기** — 고른 채널에 바로. 막힌 채널은 나머지만 올라가고 초안으로 보존.
2. **승인 인박스에 보관하기** — 올리지 않고 검토 대기.
3. **캘린더로 예약하기** — 시각 정해 자동 발행. 10분 전 알림.

편집실의 다음 단계 버튼도 "발행실로 보내기 전에 미리보기"로 고쳤다.

### 인박스 / 캘린더 depth

- 인박스: 검토 대기 3건. 되돌린 항목도 사라지지 않고 어느 방에 있는지 표시만 바뀐다.
- 캘린더: 확정 / 대기 / 빈 자리 3줄 + 시간 위임 패널(근거 라벨 + 표본 한계 + 승인 게이트).

## 5. 4번 방 · 성과 (openclaw-service)

기준 = `docs/prototype/qa-v24/studio-desktop-1024.png`와 `qa-v23/`의 실제 밀도.

| 블록 | 내용 |
|---|---|
| 운영 결과 | 발행 18 · 측정 가능 14/18 · 평균 보류 2채널 · 이번 주 저장 278. 표본 보류 규칙 문장 |
| 발행물별 결과 | 7열 × 6행 표. 노출·좋아요·댓글·채널 고유. 값 없으면 **미수집**(0 아님) |
| 이 글에 대해 할 일 | 글 3개. 각 글 **옆에** 행동 버튼(답글 달기 / 내려서 보관 / 비슷하게 만들기) |
| 자동 상호작용 | 자동 댓글 · 자동 좋아요 · 저조한 글 정리(제안만). 근거 라벨 + 말투 출처 |
| 둘러보다 만들기 | 키워드 3개 → 고른 키워드의 **실물 후보 카드**(형식 + 실제 제목 + 예상 결과 + 생성 보내기) |

- **하단 CTA 없음.** 판단 버튼은 전부 대상 옆에 있다(회장 지적 10).
- 390에서 7열 표는 열을 지우지 않고 가로 스크롤로 흡수한다.

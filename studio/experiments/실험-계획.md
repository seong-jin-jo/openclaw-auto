# 힉스필드 크레딧 실험 계획 (감 잡기)

STAMP: 2026-08-14 / [opus] / 컨트롤러 직접(실험 설계) / 근거: WebSearch 힉스필드 제품·크레딧(geo.higgsfield.ai, gstory.ai) + 대본 v7.9

## 목적
29편 올인 전에 1천 크레딧으로 (1) 어느 영상 엔진이 우리 경제콘텐츠 톤에 맞고 크레딧 대비 좋은지 (2) Soul ID 페르소나 일관성이 되는지 (3) 한글 자막·정적 카드뉴스 품질을 실측해 스코프·툴을 판단한다.

## 실험 대상: EC0147 (경기종합지수)
이유: hook "동네 카페는 만석인데 뉴스는 경기가 나쁘다"가 가장 시각적. 만석 카페 vs 불황 뉴스 대비가 이미지·영상으로 바로 나온다. 엔진 품질 차이가 잘 드러나는 장면.

## 배치 (예상 약 250크레딧, 750 버퍼 남김)
1. **Soul ID 페르소나 1컷** — "조곤" 경제 화자 캐릭터 정의(재사용 앵커). 이후 전 편·전 채널에서 이 얼굴 고정.
2. **엔진 비교 세로영상 3컷** — 동일 장면(만석 카페→불황 뉴스 대비)을 서로 다른 엔진으로:
   - Kling 3.0
   - Veo 3.1 (프리미엄, 40~70크레딧)
   - Seedance 2.0 (Marketing Studio)
   → 어느 게 톤·크레딧 대비 best인지 판정
3. **카드뉴스 커버 2장** — Soul 정적 이미지. 한글 텍스트 렌더·가독성 확인.

## 판정 기준
- 경제콘텐츠 톤: 신뢰감 있고 과장·자극 없나 (브랜드 금지선: 수익보장·리딩방 느낌 0)
- 한글 자막·텍스트가 깨지지 않고 읽히나
- 크레딧 대비 품질 (같은 장면 3엔진 비교로 가성비 판정)
- Soul ID 얼굴이 컷마다 일관되나

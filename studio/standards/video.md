# 영상 생성 품질헌법

## 1. 합격선

영상 생성물은 다음 조건을 모두 만족해야 편집 투입 가능이다.

1. 9:16 세로 파일이면서 화면 내용도 세로로 서 있다.
2. 지시한 시작 상태, 핵심 동작, 종료 상태가 순서대로 보인다.
3. 종료 금지 조건을 한 프레임도 위반하지 않는다. 예를 들어 버튼 비접촉 컷은 접촉 프레임이 1장이라도 있으면 실패다.
4. 깨진 문자, 숫자, 로고, UI가 없다.
5. 손, 얼굴, 사물 물리가 컷의 의미를 깨지 않는다.
6. 생성 원본의 시작, 중간, 끝을 포함한 프레임을 직접 검사했다.

## 2. 9:16 구도 사고 회피 규칙

EC0147에서 Kling은 3회 중 2회 컷1의 넓은 실내 군중샷을 90도 눕혔다. 같은 영상의 인물 중심 컷2와 컷3은 12개 관찰에서 눕힘이 0회였다. `vertical composition`을 추가한 프롬프트도 눕힘을 막지 못했다.

따라서 다음 규칙을 적용한다.

1. `wide shot`과 넓은 실내 군중 설정샷을 기본값으로 쓰지 않는다.
2. 공간은 테이블, 줄 선 발, 컵 놓이는 손처럼 좁은 인서트 3개로 암시한다.
3. `framed vertically like a phone recording`을 쓰지 않는다. Veo가 이를 실제 폰 UI로 해석해 녹화 버튼과 깨진 문자를 만들었다.
4. 프롬프트 명시만 믿지 않고 ffprobe로 해상도를, 추출 프레임으로 내용 방향을 따로 검사한다.
5. 넓은 설정샷이 반드시 필요하면 Veo 후보를 우선하되, 우리 표본은 1회이므로 재검사한다.

## 3. 모션 지시 문법

모션 프롬프트는 다음 7요소로 쓴다.

```text
[대상과 시작 상태]
[행동 1]
[행동 2]
[정확한 종료 상태]
[카메라와 피사체 거리]
[세로 구도]
[문자와 금지 행동]
```

검증된 예시는 다음과 같다.

```text
Photorealistic close insert of a Korean adult hand hovering above a plain matte red circular button on a clean desk.
The trembling index finger moves toward the button, then stops exactly one centimeter before contact and remains suspended.
No face, no button press, tactile skin detail, restrained tension, vertical framing.
No text, no letters, no numbers, no logos, no UI anywhere.
```

작성 규칙:

- 형용사보다 상태 변화 동사를 쓴다. `slides`, `folds`, `merges`, `stops`, `remains suspended`처럼 시작과 끝을 연결한다.
- 한 컷에 핵심 동작은 1개, 보조 동작은 최대 2개로 제한한다.
- 금지 동작은 종료 상태 바로 뒤에 둔다. `no button press`처럼 쓴다.
- 1센티처럼 서사에 중요한 거리는 마지막 0.5초 프레임 단위로 검사한다.
- 컷 전환이 필요하면 엔진별 멀티샷 문법을 사용하되, 비교 실험에서는 같은 장면과 같은 동작을 유지한다.

## 5. 길이 enum 함정

`duration`은 임의 숫자가 아니라 모델 계약이 허용하는 enum이다. 같은 8초를 모든 엔진에 넣으면 비교가 깨지거나 요청이 실패한다.

실측 벤치에서 사용한 허용 길이는 다음과 같았다.

| 모델 | 벤치에서 허용되고 사용한 길이 | 주의 |
|---|---|---|
| Veo 3.1 Lite | 8초 | 5초 통제군과 길이가 달라 모션 난이도 해석에 주의 |
| Seedance 1.5 Pro | 8초 | 견적과 실청구가 달랐음 |
| Kling 3.0 표준 | 5초, 8초, 10초 | 모드와 사운드, 4K가 단가를 바꿈 |
| Kling 3.0 Turbo | 5초 | 오디오 생성 토글이 계약에 없음 |
| Wan 2.7 | 5초, 8초 | 오디오 생성 토글이 계약에 없음 |
| Seedance 2.0 | 5초 | 5초도 22.5크레딧으로 고가 |

실행 전 순서:

```bash
higgsfield model get <job_type> --json
higgsfield generate cost <job_type> <모델별 필수 파라미터>
```

계약에 없는 길이, 화면비, 사운드 옵션을 억지로 넣지 않는다. 통제 조건을 보장할 수 없으면 해당 엔진을 비교에서 제외하고 `미검증`으로 남긴다.

## 6. 생성과 저장 규칙

1. 힉스필드 크레딧 잔액이 0이거나 생성 금지 지시가 있으면 `generate create`를 실행하지 않는다.
2. 생성 전 견적, 생성 후 실청구, 모델, 길이, 화면비, 사운드를 원장에 기록한다.
3. 자동 오디오를 끌 수 없는 엔진은 저장본에서 `ffmpeg -an`으로 제거하고 통제 예외를 공개한다.
4. 기준본은 후보가 육안 통과하기 전에 삭제하지 않는다.
5. 파일 상태를 `baseline`, `candidate`, `approved`, `rejected`로 분리한다.

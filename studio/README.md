## 0. 이 모듈이 뭔가

openclaw-auto는 **발행 플랫폼**이다. 이 `studio/`는 그 위에 얹히는 **제작 엔진**이다.

| | studio (이 모듈) | openclaw (나머지) |
|---|---|---|
| 담당 | 무엇을 어떻게 만들까 | 어디에 언제 올리고 성과를 어떻게 걷을까 |
| 결정 유형 | 창작 결정 | 채널 적응과 배포 |
| 구체적으로 | 주제 해석, 컷 분해, 프롬프트, 톤·화풍, 자막·레이아웃, 품질 게이트 | 채널별 비율 크롭, 캡션 길이, 해시태그, 예약, 계정 인증, 지표 수집, 트렌드 수집 |

**의존 방향 규칙**: `studio/`는 `extensions/`(채널 코드)를 import하지 않는다. 발행 쪽은 브랜드킷·금지선을 소유하지 않는다. 이 방향만 지키면 나중에 별도 서비스로 분리할 수 있다.

## 1. 폴더

```
studio/
├─ standards/     품질헌법. image.md video.md voice.md layout.md
├─ pipelines/     제작 스크립트(build.py)와 사용법
├─ ventures/      벤처 인테이크 양식
├─ experiments/   실험 기록과 판정 보고서, 라인별 레지스트리
└─ docs/          경쟁 벤치마킹, 포지셔닝, 인수인계

studio-assets/    (git 미추적, 614MB) 영상·이미지·음성·Soul 레퍼런스
```

에셋을 repo에 넣지 않는다. 나중에 R2로 올린다(openclaw-auto에 이미 R2 UI가 있다).

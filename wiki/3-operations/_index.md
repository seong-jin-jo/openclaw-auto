# 운영

작업 방식, 운영 런북, 결정 기록, 세션 이력을 관리한다. 제품 정의와 기술 구조는 각각 제품·개발 허브에 둔다.

## 여기 있는 것

- [런북](./runbooks/_index.md): cron, 멀티테넌트, 운영자 복구, 외부 설정.
- [의사결정](./decisions/_index.md): ADR과 가격·인증·네이밍 결정.
- [협업 가이드](./guides/_index.md): 기여, Stage Controller, 위키 유지관리.
- [과거 세션 이력](./session-state.md): 2026-08-28 이전까지 누적된 장기 로그.
- [아카이브](./archive/_index.md): 오래된 세션 기록.

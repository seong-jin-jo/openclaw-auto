# TikTok — 채널 아이덴티티 팩

**갱신: 2026-08-24 (신설, v1 = 프로필 선점까지)** · 정본 계층: 이름·핸들은 [naming.md](../naming.md), 톤·필러는 [brand.md](../brand.md), 비주얼은 [design-system.md](../design-system.md). 이 파일은 TikTok 프로필 셋업의 실행 정본.

**기반 포맷: wiki/marketing/channels/threads.md + instagram.md (9섹션 골격 상속).**

> ⚠️ **범위 = 프로필 선점 + bio·핸들 확정까지(v1).** OSMU 콘텐츠 파이프라인은 현재 텍스트(Threads)·카드뉴스(IG) 중심이라 **영상 생산 능력·계획이 정본에 없다.** TikTok은 숏폼 **영상** 플랫폼이므로, 영상 콘텐츠 케이던스는 **'영상 파이프라인 기획 전까지 보류'**로 명시한다(§4). 억지 케이던스를 채우지 않는다 — 이 갭을 닫는 것은 별도 기획 과업(⛔ 회수).
> ⚠️ 범위 근거: naming.md v1 채널 = IG+Threads. **회장 2026-07-26 전 채널 확장 지시**(IG·YouTube·Facebook·TikTok·Threads)로 TikTok 프로필팩을 신설. 계정 생성 완료(공용 이메일 j.the.great.creator@gmail.com, 계정명 OSMU).
> ✅ 표시 이름 **"OSMU 팩토리"**, 핸들 **1순위 `@osmu.official` → 실패 시 `@osmu.factory`** 계승(naming.md §2). 셋업 실행은 **회장이 화면에서 직접**(ADR-004 자동 운전 금지 — §9).

> 하위모델 규칙: 이 파일은 프로필 셋업까지만 정본이다. **영상 콘텐츠 생성 지시는 이 파일에 없다** — 영상 요청이 오면 만들지 말고 `⛔ 회수 필요`로 중단(파이프라인 미비).

**CTA 착지 경로 (1줄)**: 모든 CTA → 프로필 bio 링크 필드 → (랜딩 완성 전) 블로그 소개글([blog.md](./blog.md)) → (완성 후) `osmu.kr` waitlist([landing-copy.md](../landing-copy.md)).

## 2. Bio 확정 전문 (80자 한도 — 벤치마크 확인 2026-08-24)

TikTok bio 한도는 **80자**(전 계정 유형 공통 — 일부 계정에 120~180자 확장 롤아웃 중이나 80자가 안전 기준). 과업 지시의 "60자 내외"를 보수 기준으로 삼아 아래 전문 약 55자.

```
사장님 콘텐츠를 만들어 출고하는 콘텐츠 공장. 이 계정도 이 공장 라인. 맡길 곳 필요하면 아래 링크로.
```

- 구조 = 정체(공장) → 메타 데모("이 계정도 이 공장 라인") → CTA. [근거: TikTok bio는 "첫 80자가 단독 생존 — who you help + what you do + why tap the link" 골격, 별도 링크·이메일 버튼은 80자에 안 잡히니 bio 본문에 링크 설명을 낭비하지 말 것(replug.io / boomp.net 2026 가이드). 우리는 "이 계정도 이 공장 라인" 자기증명을 80자 안에 넣어 차별화. 문구 복붙 없음]
- **링크 필드**: bio 텍스트에 URL을 풀어 쓰지 않는다(글자 낭비) — TikTok 비즈니스 계정의 **웹사이트 링크 필드**에 별도 등록(블로그 → 랜딩 완성 후 `osmu.kr`).

### 프로필 특유 필드
| 필드 | 값 |
|---|---|
| 웹사이트 링크 | (랜딩 전) 티스토리 블로그 → (완성 후) `osmu.kr` — bio 텍스트가 아닌 링크 필드에 |
| 이메일(비즈니스) | 노출 여부는 회장 판단(FB와 동일 — 스팸 vs 인바운드 편의). 기본 비노출 권장 |
| 카테고리 | 비즈니스 계정 카테고리 = "미디어/제작" 또는 "소프트웨어" 계열 — 선택지는 설정 화면에서 회장 확인(⛔ 회수) |

## 3. 고정글 전문

TikTok은 프로필에 영상 고정을 지원(최대 3개)한다. **단, 고정할 영상 자체가 없다** — 영상 파이프라인 미비(§4)로 v1 단계에서는 고정 대상이 없다.

- **v1 = 고정글 없음.** 프로필 선점만 하고 발행은 보류.
- 영상 파이프라인 확정 후: ①소개 영상(공장 컨셉 15초) ②최신 주간 리포트 영상 ③최고 성과 영상 을 고정 슬롯에 매핑(IG 고정 3개 운영 구조 계승).
- **소개 영상 스크립트·훅은 이 파일에서 확정하지 않는다** — 영상 규격(길이·자막·음원·design-system 영상 문법)이 정본에 없어 억지로 쓰면 재작업 발생. 영상 파이프라인 기획 시 확정(⛔ 회수).

## 4. 업로드 케이던스 — **영상 파이프라인 기획 전까지 보류**

⚠️ **케이던스를 채우지 않는다.** 사유:

- OSMU 콘텐츠 파이프라인(크론 threads-generate-drafts / instagram-generate-drafts)은 **텍스트·카드뉴스만 생산**한다. 영상 생성·편집·자막·음원·발행 능력이 정본·코드 어디에도 없다.
- TikTok은 숏폼 영상이 본체인 플랫폼 — 텍스트/이미지 재활용으로는 성립하지 않는다(정지 이미지 슬라이드쇼는 가능하나 별개 기획·품질 검증 필요).
- 따라서 v1 케이던스 = **없음(프로필 선점만)**. 억지 데일리 슬롯을 여기 적으면 하위모델·크론이 만들 수 없는 걸 만들라는 지시가 되어 위조·저품질을 유발한다(품질헌법 §0 완결주의 금지).

**케이던스 확정의 선행 조건(별도 기획 과업):**
1. 영상 생산 파이프라인 결정 — 슬라이드쇼(카드뉴스 재활용) vs 자막 숏폼 vs AI 영상 생성. 각 비용·품질·자동화 가능성 검토.
2. design-system에 영상 문법 신설(현재 §4에 릴스/스토리 커버 **정지 이미지** 규격만 있음 — 영상 편집 규격 없음).
3. 크론·툴 레지스트리에 영상 발행 extension 존재 여부 확인.
4. 그 후 이 §4를 목요일 주간 리포트 축 + 데일리 로테이션 구조(threads.md·instagram.md 계승)로 채운다.

## 5. 톤 오버라이드 (프로필 문구 한정 — 영상 톤은 미정)

- **현재 정본 범위 = 프로필 문구(닉네임·bio)까지.** 영상 대본·자막 톤은 영상 파이프라인 기획 시 확정(미정 — 추측 금지).
- 프로필 문구는 공통 톤(brand.md §4) 준수: 리포트체·주어 절제·숫자로 증명. 80자 한도라 IG/FB보다 더 압축 — 첫 구절이 정체 전부.
- 공통 금지어 유지: 여러분 / 놀라운 / 혁신적인 / 게임체인저 / 꿀팁 대방출. 이모지 0–1개. AI 티·굽신 톤 금지.

## 6. 콘텐츠 유형 매핑 (필러 5 × TikTok) — 방향만, 실행은 파이프라인 후

⚠️ 아래는 영상 파이프라인 확정 시 참조할 **방향 스케치**이지 지금 생산 지시가 아니다.

| 필러 (brand.md §5) | TikTok 영상 방향(미확정) |
|---|---|
| 1. 대신 만들어 출고 | "사장님 대신 오늘 출고한 콘텐츠" 화면 녹화형 숏폼 |
| 2. 이 계정도 공장이 굴림 | 발행 큐·출고 로그 화면 캡처 숏폼("이 영상도 이 라인에서") |
| 3. 브랜드 사실을 안다 | 일반 AI 헛소리 vs 위키 그라운딩 전후 비교 숏폼 |
| 4. 시간·돈을 아낀다 | "대행 32만원 vs 공장 월 가동비" 숫자 자막 숏폼 |
| 5. 지표 공개 | 주간 리포트 숫자 모션 숏폼 |

(전부 얼굴 비노출·화면 캡처·자막 위주 — 사람 출연 없이 성립하는 포맷만. 실제 제작 가능성은 §4 선행 조건 검토 후 판정.)

## 7. 태그/키워드 세트

TikTok 해시태그는 노출 알고리즘에 관여하나 **영상이 있을 때 유효** — v1(프로필만) 단계에서는 미적용.

영상 발행 시 후보 풀(주제 맞는 3~5개): `#자영업` `#소상공인` `#사장님` `#가게마케팅` `#마케팅자동화` `#콘텐츠자동화` `#사장님꿀팁`(단 "꿀팁 대방출" 금지어와 구분 — 태그는 검색어라 허용). 도배 금지.

## 8. 프로필 개설/셋업 체크리스트 (순서만 — 실행은 회장)

⚠️ 앱 화면의 클릭 경로·버튼 이름은 추측 금지 — **화면은 회장 캡처로 확인.**

1. ~~표시 이름·핸들 낙점 선행~~ — **완료**: 이름 "OSMU 팩토리", 핸들 `@osmu.official`(1순위)→`@osmu.factory`(2순위).
2. 계정 생성(완료) → 비즈니스 계정으로 전환(웹사이트 링크·이메일 필드 활성화).
3. username(`@핸들`) 설정 — **Meta와 완전 별개**, TikTok에서 독립 확보(가용 여부는 설정 화면에서 회장 확인). 실패 시 2순위.
4. 닉네임("OSMU 팩토리")·bio(§2 전문, 80자 내)·프로필 이미지(씰+체크 v1)·카테고리(⛔ 회수) 입력.
5. 웹사이트 링크 필드에 블로그 URL(랜딩 후 osmu.kr) 등록.
6. **여기까지가 v1.** 영상 발행·고정글은 영상 파이프라인 기획 완료 후(§4 선행 조건).

## 9. 금지 사항 (채널 리스크)

- **영상 파이프라인 없이 발행 강행 금지** — 텍스트/카드뉴스를 무리하게 영상으로 변환해 저품질 슬라이드쇼를 양산하지 않는다. 프로필 선점 후 대기가 v1 규율.
- **계정 자동 운전 금지** — Meta ADR-004의 정신 계승. TikTok 계정 설정·리네임·권한은 회장이 손으로, 발행 자동화는 공식 API/승인된 도구로만. 비밀번호 기반 자동 로그인·비공식 API 금지(ToS 위반, 정지 사유).
- DM/댓글 응대는 인바운드·승인 게이트([dm-playbook.md](./dm-playbook.md)) 안에서만 — 콜드/대량 발송 금지.
- 얼굴(실사진) 사용 금지 — 비노출 확정(naming.md §2). 프사·영상 전부 심볼/화면 캡처/자막만.
- 사람인 척 금지 — AI 자동화 공장임을 bio에 명시. 투명성 = 컨셉의 핵심 자산.
- 코드·커밋에 브랜드명 금지 (공통 레포 정책).

## 2. 채널 설명 확정 전문 (1,000자 한도 — 실확인 2026-07 계승)

전문 약 340자 (한도 내 여유). **첫 150자가 검색 스니펫** — 첫 두 문장에 정체성+키워드(사장님, SNS, 콘텐츠 공장, 콘텐츠 자동화)를 몰았다.

```
사장님 콘텐츠를 만들어 출고하는 콘텐츠 공장, OSMU 팩토리입니다. 콘텐츠를 만들고, 채널별로 고치고, 올리고, 반응까지 리포트합니다 — 사장님은 장사만 하시면 됩니다.

일반 AI와 다른 점 하나. 사장님 브랜드 위키(가격·메뉴·말투·하면 안 되는 말)를 읽고 쓰기 때문에 그럴싸한 헛소리를 만들지 않습니다.

이 채널도 이 공장에서 출고됩니다. 공장이 제대로 도는지 궁금하면 이 채널이 꾸준히 올라오는지만 보면 됩니다. 매주 목요일 주간 리포트 — 출고 건수·반응·비용을 전부 실측 숫자로 올립니다.

콘텐츠 맡길 공장이 필요한 사장님은 채널 정보의 링크로 가입/문의.
```

[근거: done-for-you 서비스 카피의 공통 골격 = "우리가 다 한다 → 당신은 본업만" (doneforyou.com "installed for you", ContentWorks "saves you 10-15 hours per week" — 계승) — 우리는 시간 절감 주장 대신 "이 채널이 증거" 자기증명으로 대체. 문구 복붙 없음]

## 3. 고정글(소개) — 채널 예고편 + 커뮤니티 고정글

YouTube의 "고정글" 슬롯은 2개: ①채널 예고편(미구독자 대상 자동 재생) ②커뮤니티 탭 고정글 (탭 사용 가능 요건은 화면에서 확인 — 미검증).

**정본 — 커뮤니티 고정글 전문:**

```
이 채널, 사람이 안 굴립니다.

여기는 콘텐츠 공장, OSMU 팩토리입니다. 사장님 대신 SNS 콘텐츠를 만들고, 올리고, 반응까지 리포트합니다. 이 채널 운영도 이 공장 라인에서 돌아갑니다.

매주 목요일 주간 리포트를 올립니다: 이번 주 출고 건수 / 반응 1위 / 들어간 비용. 잘된 것만 편집하지 않고 안 된 것도 숫자로 리포트합니다.

콘텐츠 맡겨보고 싶은 사장님은 채널 정보의 링크로 가입/문의. 궁금한 건 댓글로 — 아는 건 답하고 모르는 건 모른다고 합니다.
```

**대안 — 채널 예고편(60~90초) 스크립트 골격:**

1. (0–10초, 화면: 발행 큐→자동 업로드 실화면) "지금 보시는 이 영상, 사람이 안 올렸습니다. 공장에서 출고됐습니다."
2. (10–30초) "여기는 콘텐츠 공장, OSMU 팩토리. 사장님 대신 SNS 콘텐츠를 만들고, 채널마다 맞게 고치고, 올리고, 리포트합니다."
3. (30–60초, 화면: 위키→초안 전후 비교) "일반 AI와 다른 점 하나 — 사장님 가게의 가격·메뉴·말투를 읽고 씁니다. 지어내지 않습니다."
4. (60–75초) "매주 목요일, 이 채널에 공장 주간 리포트가 올라옵니다. 공장이 제대로 도는지는 구독 전에 리포트 몇 개 보고 판단하시면 됩니다."

risk label: 1번 훅("사람이 안 올렸습니다")은 AI 반감층 이탈 가능 — 단 메타 데모(필러 2)가 컨셉의 핵심이라 채택. 4번 문장("구독 전에 판단")은 통상 CTA 문법 역행 — 톤 자산(낮은 흥분·높은 솔직함)과 정합해 채택, 전환 낮으면 표준 CTA로 교체.

## 4. 업로드 케이던스 (목요일 축 유지)

| 요일 | 슬롯 | 형태 |
|---|---|---|
| 목 | **주간 리포트 (축)** | 영상 5~10분 또는 숏츠 (초기 4주는 숏츠로 시작 — 제작비 최소) |
| 월·토 | 숏츠 1~2개 | 발행 과정 실화면 60초 / 사장님 SNS 고민 1개 정리 (필러 1·2·3) |

- 배너에 "매주 목요일"을 박았으므로 **목요일 슬롯은 결번 금지** — 롱폼이 안 되면 숏츠로라도 채운다.
- 숏츠 원소스 = 블로그 롱폼([blog.md](./blog.md))·Threads 반응 상위 글 (OSMU 파이프라인: 롱폼 1 → 숏폼 N — 이 파이프라인 자체가 제품 데모).
- 업로드 시간 기본값 목 19:00 KST (unsourced — 가설, 4주 실측 후 갱신).

## 5. 톤 오버라이드 (공통 톤 대비 이 채널만)

- **제목·썸네일이 곧 훅.** 제목 100자 한도지만 40자 이내 권장, 숫자 선행 ("출고 12건, 손 댄 시간 0분", "대행 32만원 vs 월 ₩N") — 썸네일 규칙은 design-system §6 규격 계승 (훅 3줄·12자/줄, 대비 4.5:1, 168px 판독).
- 나레이션도 공통 톤 유지: 낮은 흥분·높은 솔직함. 리포트체 정중 종결("~합니다") 기본, 주어 절제·사무적·담백하게. 과장 인트로("미쳤습니다") 금지, "여러분" 금지.
- 얼굴 비노출 — 화면 녹화(대시보드·발행 큐·실제 발행 장면) + 나레이션 포맷 기본.
- 영상 설명 첫 150자에 키워드+훅, 이후 타임스탬프·블로그/랜딩 링크.

## 6. 콘텐츠 유형 매핑 (필러 5 × YouTube)

| 필러 (brand.md §5) | YouTube 형태 |
|---|---|
| 1. 대신 만들어 출고 | 숏츠: 주제 입력→초안→승인→출고까지 한 사이클 실화면 |
| 2. 이 계정도 공장이 굴림 | 숏츠: 발행 큐→자동 업로드 실화면 ("이 영상 업로드도 이 라인에서 나감") |
| 3. 브랜드 사실을 안다 | 전후 비교 미드폼 (일반 AI 초안 vs 위키 그라운딩 초안 — 헛소리 박제) |
| 4. 시간·돈을 아낀다 | 논쟁 미드폼 ("대행 견적 vs 콘텐츠 공장 실비용" — 숫자는 실측·출처 명시) — raw 버전 발행 전 검수 |
| 5. 지표 공개 | 목요일 주간 리포트 / 월간 결산 영상 (대시보드 실화면 + 비용 내역) |

## 7. 키워드 세트 (검색/태그)

채널·영상 공통 키워드 풀 (영상당 관련 3~6개, 태그 도배 금지): `사장님 SNS` `소상공인 마케팅` `자영업 마케팅` `SNS 자동화` `콘텐츠 공장` `콘텐츠 자동화` `인스타 자동 발행` `가게 마케팅`.

제목에는 태그가 아니라 자연어 키워드로 녹인다 ("사장님 인스타, 이번 주 12건 대신 출고한 결과").

## 9. 금지 사항 (채널 리스크)

- **YouTube API 업로드 쿼터 주의**: 신규 OAuth 앱의 업로드는 심사 전 제한이 있을 수 있음 (unsourced — Developer Console 화면에서 실확인). 확인 전 자동 업로드 크론 활성화 금지.
- 브라우저 자동 로그인·비공식 업로드 경로 금지 (ADR-004 원칙의 YouTube 적용).
- 썸네일에 실사진(얼굴) 금지 — 비노출 확정. design-system §6-3 계승 (화면 캡처 또는 심볼 아트만).
- 낚시 제목-내용 불일치 금지 — 숫자 훅은 반드시 실측값 (자랑은 숫자로만 원칙의 역방향 적용: 숫자는 거짓말 못 함).
- 사람인 척 금지 — AI 자동화 공장임을 채널 설명·예고편에 명시 (투명성 = 컨셉 자산).
- 목요일 결번 금지 (§4) — 배너에 박은 약속.
- 코드·커밋에 브랜드명 금지 (공통 레포 정책).

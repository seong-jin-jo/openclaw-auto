## 2. Bio 확정 전문 (150자 한도 — 실확인 2026-07 계승)

줄바꿈 포함 약 95자 (한도 150자, 이모지·공백 포함 계산).

```
사장님의 AI 콘텐츠 비서, 오스무(OSMU)
SNS 만들고·올리고·보고까지 대신 — 이 계정도 제가 굴림
브랜드 사실을 읽고 쓰니 헛소리 없음
맡기고 싶은 사장님은 링크로
```

- 4줄 구조: ①정체(비서) ②하는 일 + 메타 데모 ③차별화(그라운딩) ④CTA. [근거: Sintra "Soshie"가 'AI 비서 인격 + 하는 일 + no extra headcount'를 프로필 축으로 쓰는 구조(sintra.ai/soshie) 차용 — 우리는 "이 계정도 제가 굴림" 자기증명을 추가. 문구 복붙 없음]
- 링크 필드: 티스토리 블로그 URL → 랜딩 완성 후 제품 랜딩(`osmu.kr`)으로 교체.

## 3. 고정글 전문 (프로필 그리드 고정 3개 한도 — 실확인 2026-07 계승)

고정 슬롯 3개 운영: ①소개 카드뉴스(아래) ②최신 주간/월간 업무 보고 ③최고 성과 릴스 (②③은 콘텐츠 쌓인 후).

**정본 — 소개 카드뉴스 (4:5, 1080×1350, 5슬라이드) 캡션:**

```
이 계정, 사람이 안 굴립니다.

저는 AI 콘텐츠 비서, 오스무(OSMU)입니다. 하는 일: 사장님이 장사하는 동안 SNS 콘텐츠를 만들고, 채널마다 맞게 고치고, 올리고, 반응을 보고합니다.

일반 AI와 다른 점: 사장님 브랜드 위키(가격·메뉴·말투·하면 안 되는 말)를 읽고 씁니다. 지어내지 않습니다.

이 계정 발행도 제가 직접 합니다. 제가 일을 잘하는지 궁금하면 이 계정이 꾸준히 올라오는지 보면 됩니다.

올리는 것
- 매주 목요일 주간 업무 보고 (발행 건수·반응 1위·비용 실측)
- 사장님 SNS 고민 정리 카드뉴스
- 발행 로그·지표 공개

SNS 맡길 비서가 필요하면 프로필 링크(대기자 등록)로.
```

- 캡션 첫 125자 안에 훅("이 계정, 사람이 안 굴립니다") + 정체 명시 — 접힘 규칙(§4) 대응.

슬라이드 구성 (design-system §6 문법 계승): ①커버 훅 "이 계정, 사람이 안 굴립니다" ②저는 누구(AI 비서) ③하는 일 1문장 + 대시보드/발행 큐 캡처 ④올리는 것 3가지 ⑤"맡기고 싶으면 링크" CTA.

**대안 캡션 (리네임 전환 공지 겸용 — 기존 계정 리네임 시나리오에서만):**

```
팔로워 2,390 계정을 오늘부터 제가 넘겨받았습니다.

저는 AI 콘텐츠 비서, 오스무(OSMU). 이 계정은 오늘부터 '사장님 SNS를 대신 굴리는 비서'의 업무 계정으로 전환됩니다 — 발행도 제가 직접 합니다.

기존에 팔로우한 분들께: 결이 달라졌으면 언팔해도 됩니다. 남는 분들께는 비서가 일하는 과정과 숫자를 전부 보여드립니다.
```

risk label: 대안은 기존 팔로워 이탈을 명시 허용하는 문안 — 팔로워 수 단기 하락 가능. 단 전환 투명성이 신뢰 자산 (brand.md 톤: 높은 솔직함). "AI가 계정을 넘겨받았다" 프레임은 AI 반감층 반발 가능 — 발행 전 회장 확인.

## 4. 업로드 케이던스 (목요일 축 유지)

| 요일 | 슬롯 | 형태 |
|---|---|---|
| 목 | **주간 업무 보고 (축)** | 카드뉴스 4:5 (블로그 롱폼의 시각 요약 — 발행 건수/반응 1위/비용) |
| 월 | 사장님 pain 공감 | 카드뉴스 또는 릴스 (필러 1·3 — "가게 인스타 뭐 올리지" 류 고민 정리) |
| 토 | 가벼운 컷 | 릴스/단일 이미지 — 발행 로그·예약 큐·대시보드 실화면 (필러 2·5) |

- 주간 총 2~3피드. 스토리는 피드 발행일에 리포스트 위주 (제작 부담 0 원칙).
- 캡션 한도 2,200자이나 **첫 125자에서 접힘** (실확인 2026-07 계승) — 훅은 반드시 첫 125자 안에.
- instagram-generate-drafts / instagram-auto-publish 크론 연결 대상 (현재 Connected, 자동화 미시작).

## 5. 톤 오버라이드 (공통 톤 대비 이 채널만)

- **시각이 본문, 캡션은 보조.** 카드뉴스 커버 1장이 Threads의 첫 문장 역할 — 커버 훅 최대 12자/줄·3줄 (design-system §6 규격 계승).
- 다른 채널보다 온도 살짝 높임: 비서의 "업무 일지" 무드 — 발행 큐 화면·아침 예약 발행 컷 등 일하는 장면 소량 허용. 단 얼굴 비노출 유지, 사람 연출 금지.
- 캡션은 Threads보다 정돈된 문장 허용 — 비서 보고체("~했습니다/올려뒀습니다") 기본, 사무적·담백하게. AI 티·"여러분"·굽신 톤 금지 동일.
- 숫자 강조 표기는 design-system §6-2 규격 계승 (재정렬 후 컬러 확정).

## 6. 콘텐츠 유형 매핑 (필러 5 × Instagram)

| 필러 (brand.md §5) | IG 형태 |
|---|---|
| 1. 대신 굴려준다 | "오늘 사장님 채널에 나간 콘텐츠" 발행 보고 카드 + 예약 큐 캡처 |
| 2. 이 계정도 비서가 굴림 | 발행 예약 화면·로그 캡처 릴스 ("이 게시물 올린 것도 저입니다") |
| 3. 브랜드 사실을 안다 | 전후 비교 카드뉴스 (일반 AI 헛소리 vs 위키 기반 문장) |
| 4. 시간·돈을 아낀다 | 비교 카드 ("대행 건당 32만원 vs 비서 월 운영비 — 실측") — 댓글 유도 |
| 5. 지표 공개 | 주간/월간 업무 보고 카드 (고정 슬롯 ② 갱신) |

## 8. 리네임 체크리스트 (순서만 — 실행은 회장)

⚠️ 앱 화면의 클릭 경로·버튼 이름은 추측 금지 — **화면은 회장 캡처로 확인.** Meta 콘솔·계정 설정의 에이전트 자동 운전은 금지 (§9).

1. ~~표시 이름·핸들 낙점 선행~~ — **완료 (2026-07-16, naming.md §2)**: 이름 "오스무 비서", 핸들 `@osmu.official`(1순위)→`@osmu.secretary`(2순위).
2. **리네임 전 확인 (naming.md §5 잔여 항목)**: 기존 팔로워 2,390이 무엇을 보고 팔로우했는지 확인 — 주제가 현재(사장님 타겟)와 전혀 다르면 리네임 대신 신규 개설 재검토.
3. 기존 핸들·계정명 기록 (롤백 대비 — IG는 리네임 후 일정 기간 구 핸들이 잠금 보호되는 것으로 알려져 있으나 unsourced, 화면에서 확인).
4. `@osmu.official`로 리네임 시도 (가용 여부는 리네임 화면에서 최종 확인 — 비로그인 조회 불가). 실패 시 `@osmu.secretary`로 재시도.
5. 이름(낙점값) / bio(§2) / 링크 / 프로필 이미지(비서 심볼 — 재제작 후) 교체.
6. Threads에 핸들·프로필 연동 반영 확인 ([threads.md](./threads.md) §8).
7. 전환 공지 발행 (§3 대안 캡션 — 회장 확인 후) → 소개 카드뉴스 발행 → 그리드 고정.
8. 대시보드 채널 Settings의 `INSTAGRAM_ACCESSTOKEN`/`INSTAGRAM_USERID` 유효성 재검증 (리네임이 토큰에 영향 없는지 테스트 발행 1건으로 확인).

## 9. 금지 사항 (채널 리스크)

- **Meta 콘솔·계정 설정 자동 운전 금지 — 실제 사고 이력.** 2026-07-01 GStack 브라우저로 Meta 콘솔 자동 운전 중 개발자 계정 플래그("비정상적인 활동 감지", 액세스 차단). [ADR-004](../../decisions/004-social-connect-oauth-not-passwords.md)로 확정: 콘솔 셋업·계정 조작은 사람이 손으로, 제품 자동화는 공식 API(OAuth/토큰)만.
- 비밀번호 기반 자동화·비공식 API 금지 (Meta ToS — 계정 정지 사유).
- 리네임 직후 대량 자동 발행 금지 — 계정 변경 + 발행 패턴 급변 조합은 스팸 시그널 리스크 (unsourced — 보수 운영 원칙). 첫 2주는 수동 승인 발행만.
- 해시태그 30개 채우기·팔로우 어뷰징·DM 대량 발송 금지.
- 실사진(얼굴) 사용 금지 — 비노출 확정 (naming.md §2). 썸네일·프로필 전부 심볼/화면 캡처만.
- 사람인 척 금지 — AI 비서임을 bio·고정글에 명시 (투명성 = 컨셉의 핵심 자산).
- 코드·커밋에 브랜드명 금지 (공통 레포 정책).

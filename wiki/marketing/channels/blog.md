## 3. 고정글(대표 소개글) 전문

공지 카테고리에 발행 후 블로그 상단 고정(스킨별 공지 기능 — 화면에서 확인). SNS 고정글보다 길게 — 검색 유입자가 처음 읽는 관문.

**정본 (그대로 발행):**

```
# 이 블로그 소개 — 사장님 SNS를 대신 굴리는 AI 비서의 업무 기록

이 블로그의 주인은 사람이 아닙니다. 사장님 SNS를 대신 굴리는 AI 콘텐츠 비서, 오스무(OSMU)입니다 — 주제나 가게 사실 몇 줄만 받으면 스레드·X·인스타그램·유튜브·블로그에 맞게 콘텐츠를 만들어 올리고, 반응까지 보고합니다.

## 일반 AI와 다른 점

사장님 브랜드 위키 — 가격, 메뉴, 말투, 하면 안 되는 말 — 를 읽고 씁니다. 그래서 그럴싸한 헛소리를 만들지 않습니다. "네 브랜드 위키를 아는 콘텐츠 자동화 — 헛소리 없는 자동 발행"이 한 줄 소개입니다.

## 이 블로그가 특이한 점

이 블로그를 포함한 소셜 계정들의 발행을 제가 직접 합니다. 제가 일을 잘하는지 궁금하면 이 계정들이 꾸준히 올라오는지만 보면 됩니다. 여기가 그 업무의 원본 기록소 — SNS로 나가는 글 대부분이 이 롱폼에서 잘려 나갑니다.

## 올리는 것

- **매주 목요일 주간 업무 보고**: 이번 주 발행 건수 / 반응 1위 / 들어간 비용. 전부 실측 숫자로, 안 된 것도 포함해서.
- **사장님 SNS 질문 해부**: "가게 인스타 뭐 올리지", "대행 비용이 왜 이렇게 비싸지" 같은 질문을 1개씩 정리. 질문 → 현실 → 해법 순.
- **지표·비용 공개**: 채널이 실제로 얼마나 도는지, 운영비가 얼마 드는지 표로.

## 누구한테 유용한가

SNS 해야 하는 건 아는데 만들 시간도 감도 없는 사장님. 맡겨보고 싶으면 대기자 등록(링크)으로 — 자리 나는 순서대로 초대합니다. 궁금한 건 댓글로, 아는 건 답하고 모르는 건 모른다고 합니다.
```

**대안 (검색 유입 최적화형 — 도입부를 pain 서술로 교체):**

첫 단락을 아래로 교체, 나머지 동일:

```
"SNS 해야 하는 건 아는데, 마감하고 나면 올릴 힘이 없다" — 이 블로그는 그 일을 대신하는 AI 콘텐츠 비서, 오스무(OSMU)의 업무 기록입니다. 사장님 대신 콘텐츠를 만들어 올리고, 매주 목요일 결과를 숫자로 보고합니다.
```

## 4. 업로드 케이던스 (목요일 축 유지)

| 요일 | 슬롯 | 형태 |
|---|---|---|
| 목 | **주간 업무 보고 롱폼 (축·원소스)** | 1,500~3,000자 + 스크린샷 — 이 글이 그 주 전 채널 콘텐츠의 원본 |
| 화 | pSEO "사장님 SNS 질문 해부" 1편 | 800~1,500자, 1질문 1글, 고정 골격(§7) |

## 5. 톤 오버라이드 (공통 톤 대비 이 채널만)

- **유일한 롱폼 채널.** 문장 완결도를 SNS보다 올린다 — 비서 보고체 정중 종결("~합니다/올려뒀습니다") 기본, 사무적·담백. AI 티 금지 동일: 뻔한 정리체·과잉 소제목 나열 금지.
- 검색 유입자 전제: 글 서두 3문장 안에 "이 글이 답하는 사장님 질문"을 명시 (SEO 스니펫 대응).
- 제목 = 검색어 + 숫자 훅: "인스타 대행 비용, 견적 3개 실측 비교" 식. 낚시 금지 — 숫자는 실측만.
- 소제목(H2/H3) 구조 필수, 지표·비용은 표로. 이미지에 alt 텍스트.
- 공통 금지어(여러분/놀라운/혁신적인/게임체인저/꿀팁 대방출) 유지. "꿀팁" 류 SEO 제목 관습에 끌려가지 말 것.

## 7. 키워드 세트 + pSEO 시드 구조

**pSEO 시드 = "사장님 SNS 질문 해부" 아카이브.** 사장님이 검색할 롱테일 질문 1개 = 글 1개, 동일 골격(질문 → 현실(숫자) → 해법 → 맡기는 선택지)으로 반복 생산 — OpenClaw 크론이 대량 생성 가능한 구조.

| 클러스터 | 시드 키워드 (제목·본문에 자연 포함) |
|---|---|
| 제품 카테고리 (선점) | `콘텐츠 자동화` `SNS 자동 발행` `AI 콘텐츠 비서` `OSMU 자동화` `원소스 멀티유즈` |
| 타겟 pain (질문 해부) | `가게 인스타 뭐 올리지` `인스타 대행 비용` `사장님 SNS 운영` `소상공인 SNS 마케팅` `자영업 마케팅` |
| 서사 (업무 보고) | `AI 비서 실사용` `SNS 자동화 후기` `SNS 운영 비용 공개` `마케팅 자동화 비용` |

[근거: 대행 비용은 실측 검색 수요 존재 — 숨고 가격 페이지(건당 평균 32만원)·아이보스 질문글(대행 비용 문의)·크몽 카테고리가 이미 그 검색을 받고 있음. 우리는 "비용 실측 공개 + 대안 제시" 각으로 진입]

- 글당 클러스터 1개·키워드 2~4개만 — 키워드 스터핑 금지 (카카오 저품질 필터 리스크, §9).
- "OSMU 자동화"는 카테고리=브랜드 SEO 선점 전략 (naming.md §1 근거 3) — 주간 업무 보고 롱폼마다 1회 자연 언급.
- 태그: 글당 3~5개, 위 시드 풀에서만.

## 8. 개설 체크리스트 (순서만 — 실행은 회장)

⚠️ 티스토리 콘솔 클릭 경로·버튼 이름 추측 금지 — **화면은 회장 캡처로 확인.**

1. 표시 이름·주소 낙점 선행 (naming.md §5) — 낙점 전 개설 실행 금지.
2. 카카오 계정으로 티스토리 블로그 개설, 잠정 주소 `osmu` 가용 확인 (불가 시 백업 순서대로).
3. 블로그 이름(낙점값) / 닉네임 / 설명(§2) / 프로필 이미지 설정.
4. 카테고리 구조 생성: `주간 업무 보고` / `사장님 SNS 질문 해부` / `지표·비용` / `공지` — §6·§7 구조와 1:1.
5. 대표 소개글(§3 정본) 발행 → 공지 고정 (스킨별 공지 기능 화면 확인).
6. 전 SNS bio 링크 필드에 블로그 URL 반영 (threads/x/instagram/youtube.md §2).
7. **발행 자동화 경로 결정**: 티스토리 공식 Open API는 2024년 중단된 것으로 알려져 있음 (unsourced — 계승) — blog_queue → 발행의 실경로(수동 붙여넣기 vs 대체 수단)를 확정해야 자동화 범위가 정해짐 (⛔ 회수).
8. 검색 등록: 구글 서치콘솔·네이버 서치어드바이저에 소유 확인 + 사이트맵 제출 (콘솔 화면은 회장 캡처로).

- **카카오 저품질 필터**: AI 대량생성 글 도배·키워드 스터핑·복붙성 글은 검색 누락(저품질) 리스크 (unsourced — 티스토리 운영 통념, 계승). 크론 생성 글도 반드시 §5 톤·§7 키워드 규율 통과분만 발행. 주 2글 상한 유지. **비서 컨셉이라 해서 "AI가 쓴 글" 태그를 남발하지 말 것 — 저품질 필터와 별개로, 본문 품질 자체가 방어선.**

- 비공식 API·브라우저 자동 로그인으로 발행 자동화 금지 (ADR-004 원칙의 티스토리 적용 — 계정 제재 리스크).
- 타 블로그·대행사 문구 복붙 금지 — 벤치마크는 구조 분해용 (brand.md 계보). 대행 비용 인용 시 출처 명시.

- 코드·커밋에 브랜드명 금지 (공통 레포 정책) — 이 파일 포함 브랜드 지식은 wiki에만.

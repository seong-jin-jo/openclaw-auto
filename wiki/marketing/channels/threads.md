## 2. Bio 확정 전문 (150자 제한 — 실확인 2026-07 계승)

Threads bio 한도 150자, IG와 동일(가입 시 IG 프로필을 가져옴). 아래 전문 약 80자.

```
사장님 SNS는 제가 대신 굴립니다 — 브랜드 사실을 읽고 쓰는 AI 콘텐츠 비서, 오스무(OSMU). 이 계정 발행도 제가 함. 매주 목요일 업무 보고
```

- "이 계정 발행도 제가 함" = 메타 데모(필러 2) 전면 명시 — 계정 자체가 살아있는 제품 데모(brand.md §2). [근거: Sintra "Soshie" 등 이름 붙은 AI 소셜 비서 페르소나가 이미 카테고리로 성립(sintra.ai/soshie) — 우리는 '비서가 자기 계정을 직접 굴리는 투명성'으로 차별화]
- Threads bio가 IG와 별도 편집 가능한지는 화면에서 확인(미검증) — 별도 편집 가능하면 위 전문 그대로, 자동 동기화면 IG bio([instagram.md](./instagram.md) §2)가 우선.

## 3. 고정글 전문

Threads는 프로필에 글 고정 지원 (근거 확인: help.instagram.com/323726840378106 "Pin a post on Threads" — 계승). 발행 후 고정한다. 글 한도 500자 — 아래 전문 약 370자.

**정본 (그대로 발행):**

```
채용 인사 대신 업무 소개를 올립니다.

저는 AI 콘텐츠 비서, 오스무(OSMU)입니다. 하는 일은 하나 — 사장님이 장사에 집중하는 동안 SNS 콘텐츠를 만들고, 채널마다 맞게 고치고, 올리고, 반응까지 보고합니다.

일반 AI와 다른 점: 사장님 브랜드 위키(가격·메뉴·말투·하면 안 되는 말)를 읽고 씁니다. 지어내지 않습니다.

이 계정도 제가 굴립니다. 제가 일을 잘하는지 궁금하면 이 계정이 꾸준히 올라오는지만 보면 됩니다.

올리는 것:
- 매주 목요일 주간 업무 보고 (발행 건수·반응 1위·비용 실측)
- 사장님 SNS 고민 대신 정리
- 발행 로그·지표 공개

SNS 맡길 비서가 필요한 사장님은 프로필 링크(대기자 등록)로.
```

**대안 (raw provocative — 반응 실험용):**

```
사장님, 솔직히 그 시간에 장사하시는 게 낫습니다.

인스타 캡션 붙잡고 있는 1시간 — 그 시간의 원가를 계산해 본 적 있으세요? 저는 그 일을 대신하려고 만들어진 AI 콘텐츠 비서입니다. 만들고, 올리고, 반응까지 보고합니다.

못 믿겠으면 이 계정을 보면 됩니다. 여기 올라오는 글, 제가 발행합니다. 매주 목요일 업무 보고로 숫자까지 깝니다.

맡겨보고 싶으면 프로필 링크로.
```

risk label: 대안은 "그 시간에 장사하세요" 훈수 톤 — 사장님 자존심 자극 리스크. 정본으로 시작, 4주 후 반응 보고 교체 검토.

## 4. 업로드 케이던스 (목요일 축 유지)

| 요일 | 슬롯 | 내용 |
|---|---|---|
| 목 | **주간 업무 보고 (축)** | 이번 주 발행 건수 / 반응 1위 / 들어간 비용 — 계정의 척추. 숫자는 실측만, 발행 전 운영자 검수 |
| 월·화·수·금 | 데일리 1회 | 필러 1·3·4 로테이션 (자동화 발행 가능) |
| 토 또는 일 | 주 1회 | 사장님 pain 공감·반응파악 글 |

- 주간 총 6~8글. 시간대 기본값 아침 08:00 / 저녁 21:00 KST (unsourced — 가설, 첫 4주 insights 실측 후 이 표를 갱신한다).
- 저조 글 자동 삭제 크론(threads-collect-insights) 동작 중 — 고정글·주간 보고는 삭제 대상에서 제외할 것.

## 5. 톤 오버라이드 (공통 톤 대비 이 채널만)

- **가장 raw한 채널.** 비서의 짧은 업무 메모체 — "오늘 나간 글 3건. 반응 1위는 이거." 첫 문장이 훅 전부, 500자 안에서도 3줄 안에 승부.
- 대화 유도 마무리 허용: "사장님은 어떻게 하고 계세요?" 류 질문형 엔딩 OK (단 "여러분" 금지 유지).
- 실패·한계 보고 비중을 다른 채널보다 높게 — "이번 주 1건은 반응이 죽었음. 원인 분석:" 식. 비서가 실수까지 숫자로 보고하는 것이 신뢰 자산(brand.md §4).
- 공통 금지어 유지: 여러분 / 놀라운 / 혁신적인 / 게임체인저 / 꿀팁 대방출. 이모지 0–1개. 굽신 콜센터 톤 금지.

## 6. 콘텐츠 유형 매핑 (필러 5 × Threads)

| 필러 (brand.md §5) | Threads 형태 |
|---|---|
| 1. 대신 굴려준다 | "오늘 사장님 채널에 나간 글" 발행 보고 단문 + 예약 큐 캡처 |
| 2. 이 계정도 비서가 굴림 | "이 글도 제가 올림" + 발행 로그 타임스탬프 캡처 |
| 3. 브랜드 사실을 안다 | 전후 비교 글 (일반 AI 초안 vs 위키 그라운딩 초안 — 헛소리 1개 박제) |
| 4. 시간·돈을 아낀다 | 숫자 단문 ("대행 견적 건당 평균 32만원. 제 이번 달 운영비: ₩XX,XXX") |
| 5. 지표 공개 | 목요일 주간 업무 보고 스레드 (본문 + 답글로 지표 캡처) |

## 7. 태그/키워드 세트

Threads는 해시태그 대신 **토픽 태그 1글 1개** 구조 (unsourced — 발행 화면에서 확인, 계승). 도배 자체가 불가능하지만 규율 명시: 글당 태그 최대 1개, 없어도 됨.

로테이션 태그 후보: `자영업` / `소상공인` / `사장님` / `마케팅자동화` / `AI비서` (5개 중 글 주제에 맞는 1개만).

## 9. 금지 사항 (채널 리스크)

- **Meta 콘솔·계정 설정 자동 운전 금지** — 2026-07-01 실제 사고: GStack 브라우저 자동 운전 중 Meta 개발자 계정 플래그(봇 탐지, 액세스 차단). [ADR-004](../../decisions/004-social-connect-oauth-not-passwords.md) 확정. 계정 설정·리네임·권한은 회장이 손으로, 발행은 공식 API 토큰으로만.
- 비밀번호 기반 자동 로그인 금지 (Meta ToS 위반 — ADR-004).
- Threads 토큰은 60일 long-lived — 만료 전 갱신 운영 필요 (CLAUDE.md 환경변수 참조).
- 저조 글 자동 삭제 크론이 고정글·주간 보고를 지우지 않게 예외 처리 확인.

- 코드·커밋에 브랜드명 금지 (공통 레포 정책) — 브랜드 지식은 wiki에만.

# Naming — 제품명·계정명 확정 정본

**갱신: 2026-07-16 (표시 이름 낙점 완료)** · 결정자: 회장 확정 (2026-07-16, launch-pack 실행 지시) — **표시 이름·핸들 우선순위 확정. 계정 리네임 실행(화면 조작)은 여전히 회장 수동.**

> 하위모델 규칙: 제품명·계정 컨셉·핸들·태그라인은 **이 파일이 유일한 진실원**이다. 다른 문서에 다른 표기가 보이면 이 파일이 이긴다. 임의 변형(번역·축약·신규 작명) 금지.

> ⚠️ 2026-07-11 방향 전환: 구 "빌드로그 SJ"(개발자 build-in-public 페르소나)는 **폐기**(회장 veto: "말같지도 않은 브랜드"). 새 방향 = **AI 콘텐츠 비서** — 사장님이 비서를 고용한 것처럼 느끼는 done-for-you 브랜드. "공장" 세계관도 검토했으나 회장 명시 기각("공장 아님 비서야"). 개발자·바이브코더 타겟 → **사장님·자영업자**로 전환.

## 1. 제품명 = **OSMU (오스무)** (유지)

| 항목 | 확정값 |
|---|---|
| 영문 표기 | **OSMU** (전부 대문자) |
| 한글 표기 | **오스무** |
| 풀네임(설명용) | One Source Multi Use — 원소스 멀티유즈 자동화 |
| 태그라인(국문) | "네 브랜드 위키를 아는 콘텐츠 자동화 — 헛소리 없는 자동 발행" ([positioning.md](./positioning.md) 정본) |
| 도메인 1순위 | `osmu.kr` (2026-07-10~11 DNS 조회 NS없음 = 미등록 신호 — **등록은 회장 실행**) |
| 도메인 백업 | `getosmu.com` · `osmu.co.kr` · `useosmu.com` (전부 미등록 신호 관찰) |

**근거 (실조사 2026-07-10, 관찰됨):** 구 가칭 SoloClaw는 `soloclaw.dev`(동일 OpenClaw 생태계 라이브 상용 서비스)로 선점돼 기각. OSMU 채택 = ①내부 정본 이름(대시보드 `openclaw-dashboard-osmu`) 계승 → 전환비용 0 ②"원소스 멀티유즈" = 제품 기능(롱폼 1개 → 멀티채널 N개) 그 자체 = 카테고리 검색어 선점 ③2음절 "오스무" 발음 쉬움. 약점(정직): 업계 일반용어라 상표 방어력 낮음 — 부트스트랩 단계 SEO 이득 우선, 글로벌 확장 시 재검토.

**표기 규칙:** 문서 첫 등장 시 "OSMU(오스무)", 이후 상황에 맞게. 조사 붙일 땐 한글("오스무가"). "OpenClaw"는 런타임 기술 이름으로만, 제품 마케팅 카피에는 넣지 않는다.

## 2. 계정 브랜드 = **AI 콘텐츠 비서 (사장님 done-for-you)**

### 컨셉 (확정)
계정 = 제품(OSMU)이 곧 **사장님의 AI 콘텐츠 비서**로 인격화된 것. 사장님(자영업자·1인 대표)이 유능한 비서를 고용한 것처럼 느낀다 — "SNS·콘텐츠는 제가(오스무 비서가) 대신 굴립니다." 계정 자체가 그 비서가 운영하는 채널 = 살아있는 데모.

| 항목 | 확정 | 상태 |
|---|---|---|
| 컨셉 | AI 콘텐츠 비서 (done-for-you, 사장님이 고용한 느낌) | **확정** |
| 타겟 | 사장님·자영업자·1인 대표 (콘텐츠를 직접 못/안 만드는 사람) | **확정** (§전환) |
| 표시 이름 | **"오스무 비서" (OSMU)** | **확정 (2026-07-16 회장 낙점)** — 이 문자열을 문서·카피에 하드코딩 가능 |
| 통일 핸들 | **1순위 `@osmu.official`, 확보 실패 시 2순위 `@osmu.secretary`** | **확정 (우선순위)** — 실가용 여부는 IG 리네임 화면에서 회장이 직접 확인·실행 (자동화 금지, ADR-004) |
| v1 채널 범위 | **Instagram + Threads만** (X 제외) | **확정 (2026-07-16)** — X는 별도 검토 없이 v1 스코프 밖. 근거: 계정 리소스 집중 + 기존 IG(팔로워 2,390)·Threads(Live) 자산 재사용이 가장 빠른 경로 |
| 계정 셋업·리네임 실행 | **회장 수동 전용** | **확정 — 이유 명시**: 2026-07-01 GStack 브라우저 자동 운전 중 Meta 개발자 계정이 "비정상 활동 감지"로 플래그된 이력(ADR-004) — 동일 계정군에 자동 운전 재시도는 재차 플래그·정지 리스크. 화면 조작은 전부 사람이 손으로 |
| 얼굴 노출 | **비노출** (비서=서비스 인격, 사람 얼굴 불필요) | 확정 — 비서 컨셉과 강정합 |
| 목소리 | 유능한 실무 비서 — 담백·간결·숫자로 보고. 굽신 콜센터 톤·과장·AI 티 금지 | 확정 (brand.md 톤) |
| DM 자동화 | **콜드/대량 발송 자동화 금지.** 인바운드 문의·명시 요청 후 댓글→DM·기존 지인 warm 연락·후속·수신거부 처리만, 전부 사람 승인 게이트 | **확정 (2026-07-16)** — 상세 = [dm-playbook.md](./dm-playbook.md) |

### 타겟 전환 (2026-07-11, 회장 결정)
- **전환 전**: 바이브코더 + 멘토 개발자 (직접 만드는 사람) — 구 빌드로그 페르소나의 타겟. 폐기.
- **전환 후**: **사장님·자영업자 (대신 해줌)** — [product/vision.md](../product/vision.md) 제품 타겟("코딩/자동화 능력 없는 일반인·자영업자")과 일치. 그동안 brand-kit이 개발자 쪽으로 드리프트했던 것을 제품 타겟으로 정렬 교정.
- 구 "멘토링/스터디 커뮤니티" 최종 목표는 **후순위로 강등** (done-for-you 비서 브랜드와 상충 — 배우려는 사람 vs 맡기려는 사람).

### 핸들 실사 (2026-07-10~11, 우선순위는 2026-07-16 확정)
- YouTube `@osmu` 계열: HTTP 404 = 가용 신호(관찰됨). v1 범위 밖(Instagram+Threads만) — 참고용으로만 보존.
- Instagram: 비로그인 200(로그인월 — 판별 불가, 자동 조회 한계). **`@osmu.official` 1순위, 실패 시 `@osmu.secretary` 2순위** — 최종 가용 여부는 **리네임 화면에서 회장이 직접 확인**(자동 조회로 대체 불가 — 로그인월 + ADR-004 자동 운전 금지 이중 제약).
- Threads: IG 핸들 자동 연동 — 별도 확보 절차 없음.
- 리네임/개설 실행 절차 = [channels/instagram.md](./channels/instagram.md) §8, [channels/threads.md](./channels/threads.md) §8 체크리스트. 실행 주체 = 회장(수동, 확정 사유는 위 표).

# ADR-005: 제품명 OSMU(오스무) 확정 · 계정 브랜드 = AI 콘텐츠 비서 (사장님 done-for-you)

- 상태: Accepted (컨셉·타겟 확정 / 표시 이름 문자열은 회장 최종 낙점 대기)
- 날짜: 2026-07-10 최초 · **2026-07-11 개정 (계정 방향 전환)**
- 결정자: Fable 5 수렴 + 회장 컨펌

## 맥락

- 제품명이 "가칭 SoloClaw"로 방치돼 랜딩·카피·하위모델 작업 전반에 이름 구멍이 있었다.
- 계정 아이덴티티는 2026-07-07 브랜드킷이 3안 제안 후 회장 미결정으로 정체 → 2026-07-10 Fable이 "빌드로그 SJ"로 확정 시도했으나 **회장 veto**("말같지도 않은 브랜드").
- 근본 원인 = 브랜드킷이 개발자·바이브코더 build-in-public 각도로 드리프트해, 제품의 실제 타겟(자영업자·사장님, done-for-you)과 어긋난 페르소나를 만든 것.

## 결정

1. **제품명 = OSMU(오스무)** — SoloClaw 기각(soloclaw.dev 선점, 2026-07-10 실조사). 내부 정본 이름 계승 + "원소스 멀티유즈" = 제품 기능 = 카테고리 검색어. 상표 방어력 낮음은 수용된 리스크.
2. **계정 브랜드 = AI 콘텐츠 비서** — 사장님(자영업자·1인 대표)이 유능한 비서를 고용한 것처럼 느끼는 done-for-you 브랜드. 계정=제품(OSMU)의 인격화, 계정 자체가 살아있는 데모. 얼굴 비노출(비서=서비스 인격). "공장" 세계관은 검토 후 회장 명시 기각.
3. **타겟 전환**: 개발자·바이브코더·멘토링 커뮤니티(직접 만드는 사람) → **사장님·자영업자(맡기는 사람)**. vision.md 제품 타겟과 정렬.
4. **표시 이름 문자열**은 잠정 "오스무 비서" — 회장 최종 낙점 대기(브랜드킷 프리뷰안 전부 기각). 컨셉은 확정이라 하위 문서 캐스케이드는 진행.
5. 상세·조사 로그·표기 규칙·이름 계층 = [marketing/naming.md](../marketing/naming.md) (정본).

## 결과

- 모든 마케팅 문서·카피·에셋·하위모델 브리프는 naming.md를 참조 — 표시 이름은 하드코딩 대신 참조 관행. 낙점 시 naming.md 한 곳 수정으로 전파.
- 구 "빌드로그 SJ"·개발자 build-in-public 목소리로 쓰인 채널/카피/후크/브리프는 **AI 비서·사장님 타겟으로 재캐스케이드 필요** (2026-07-11 진행).
- vision.md "상품 이름" 절은 본 ADR을 가리킴. positioning.md("브랜드 위키를 아는 콘텐츠 자동화")는 비서 컨셉과 정합 → 유지.
- 도메인 등록·계정 리네임·표시 이름 낙점 = 회장 실행 항목.

## 이력
- 2026-07-10: 제품 OSMU·계정 "빌드로그 SJ" 확정 시도.
- 2026-07-11: 계정 "빌드로그 SJ" veto → AI 콘텐츠 비서 + 사장님 타겟으로 개정. 제품 OSMU 유지.

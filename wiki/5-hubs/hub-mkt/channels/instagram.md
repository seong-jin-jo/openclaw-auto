## 2. Bio 확정 전문 (150자 한도 — 실확인 2026-07 계승)

줄바꿈 포함 약 90자 (한도 150자, 이모지·공백 포함 계산).

```
사장님의 콘텐츠 공장, OSMU 팩토리
만들고·올리고·보고까지 — 이 계정도 이 공장이 굴림
브랜드 사실을 읽고 쓰니 헛소리 없음
맡기고 싶은 사장님은 링크로
```

- 4줄 구조: ①정체(공장) ②하는 일 + 메타 데모 ③차별화(그라운딩) ④CTA. [근거: done-for-you 프로필의 공통 축 = "정체 + 하는 일 + 당신은 본업만" 골격(구판 조사 계승) + "content factory" 카테고리 네이밍 성립(contentfac.com, 2026-07-16 확인) — 우리는 "이 계정도 이 공장이 굴림" 자기증명을 추가. 문구 복붙 없음]
- 링크 필드: 티스토리 블로그 URL → 랜딩 완성 후 제품 랜딩(`osmu.kr`)으로 교체.

## 3. 고정글 전문 (프로필 그리드 고정 3개 한도 — 실확인 2026-07 계승)

고정 슬롯 3개 운영: ①소개 카드뉴스(아래) ②최신 주간/월간 리포트 ③최고 성과 릴스 (②③은 콘텐츠 쌓인 후).

**정본 — 소개 카드뉴스 (4:5, 1080×1350, 5슬라이드) 캡션 (launch-pack IG-PIN-01과 동일 원문):**

```
이 계정, 사람이 안 굴립니다.

여기는 사장님의 콘텐츠 공장, OSMU 팩토리입니다. 하는 일: 사장님이 장사하는 동안 SNS 콘텐츠를 만들고, 채널마다 맞게 고치고, 올리고, 반응을 리포트로 보고합니다.

일반 AI와 다른 점: 사장님 브랜드 위키(가격·메뉴·말투·하면 안 되는 말)를 읽고 씁니다. 지어내지 않습니다.

이 계정 발행도 이 공장 라인에서 나갑니다. 공장이 제대로 도는지 궁금하면 이 계정이 꾸준히 올라오는지 보면 됩니다.

출고되는 것
- 매주 목요일 주간 리포트 (출고 건수·반응 1위·비용 실측)
- 사장님 SNS 고민 정리 카드뉴스
- 출고 로그·지표 공개

콘텐츠 맡길 공장이 필요하면 프로필 링크로 가입/문의 주세요. 지금은 공개 베타 운영 중입니다.
```

- 캡션 첫 125자 안에 훅("이 계정, 사람이 안 굴립니다") + 정체 명시 — 접힘 규칙(§4) 대응. (CTA는 2026-07-16 품질게이트 기준 "가입/문의·공개 베타"로 통일 — 구 "대기자 등록" 폐기.)

슬라이드 구성 (design-system §6 문법 계승): ①커버 훅 "이 계정, 사람이 안 굴립니다" ②여기는 어디(콘텐츠 공장 OSMU 팩토리) ③하는 일 1문장 + 대시보드/발행 큐 캡처 ④출고되는 것 3가지 ⑤"맡기고 싶으면 링크" CTA.

**대안 캡션 (리네임 전환 공지 겸용 — 기존 계정 리네임 시나리오에서만):**

```
팔로워 2,390 계정을 오늘부터 공장이 넘겨받았습니다.

여기는 OSMU 팩토리 — 사장님 콘텐츠를 대신 만들어 출고하는 콘텐츠 공장. 이 계정은 오늘부터 그 공장의 출고 라인으로 전환됩니다. 발행도 라인에서 직접 나갑니다.

기존에 팔로우한 분들께: 결이 달라졌으면 언팔해도 됩니다. 남는 분들께는 공장이 돌아가는 과정과 숫자를 전부 보여드립니다.
```

risk label: 대안은 기존 팔로워 이탈을 명시 허용하는 문안 — 팔로워 수 단기 하락 가능. 단 전환 투명성이 신뢰 자산 (brand.md 톤: 높은 솔직함). "AI 공장이 계정을 넘겨받았다" 프레임은 AI 반감층 반발 가능 — 발행 전 회장 확인.

## 4. 업로드 케이던스 (목요일 축 유지)

| 요일 | 슬롯 | 형태 |
|---|---|---|
| 목 | **주간 리포트 (축)** | 카드뉴스 4:5 (블로그 롱폼의 시각 요약 — 출고 건수/반응 1위/비용) |
| 월 | 사장님 pain 공감 | 카드뉴스 또는 릴스 (필러 1·3 — "가게 인스타 뭐 올리지" 류 고민 정리) |
| 토 | 가벼운 컷 | 릴스/단일 이미지 — 출고 로그·예약 큐·대시보드 실화면 (필러 2·5) |

- 주간 총 2~3피드. 스토리는 피드 발행일에 리포스트 위주 (제작 부담 0 원칙).
- 캡션 한도 2,200자이나 **첫 125자에서 접힘** (실확인 2026-07 계승) — 훅은 반드시 첫 125자 안에.
- instagram-generate-drafts / instagram-auto-publish 크론 연결 대상 (현재 Connected, 자동화 미시작).

## 5. 톤 오버라이드 (공통 톤 대비 이 채널만)

- **시각이 본문, 캡션은 보조.** 카드뉴스 커버 1장이 Threads의 첫 문장 역할 — 커버 훅 최대 12자/줄·3줄 (design-system §6 규격 계승).
- 다른 채널보다 온도 살짝 높임: 공장 "가동 일지" 무드 — 발행 큐 화면·아침 예약 출고 컷 등 라인이 도는 장면 소량 허용. 단 얼굴 비노출 유지, 사람 연출 금지.
- 캡션은 Threads보다 정돈된 문장 허용 — 리포트체("~했습니다/올려뒀습니다") 기본, 사무적·담백하게. 주어 절제(brand.md §4), AI 티·"여러분"·굽신 톤 금지 동일.
- 숫자 강조 표기는 design-system §6-2 규격 계승.

## 9. 금지 사항 (채널 리스크)

- **Meta 콘솔·계정 설정 자동 운전 금지 — 실제 사고 이력.** 2026-07-01 GStack 브라우저로 Meta 콘솔 자동 운전 중 개발자 계정 플래그("비정상적인 활동 감지", 액세스 차단). [ADR-004](../../../3-operations/decisions/004-social-connect-oauth-not-passwords.md)로 확정: 콘솔 셋업·계정 조작은 사람이 손으로, 제품 자동화는 공식 API(OAuth/토큰)만.
- 비밀번호 기반 자동화·비공식 API 금지 (Meta ToS — 계정 정지 사유).
- 리네임 직후 대량 자동 발행 금지 — 계정 변경 + 발행 패턴 급변 조합은 스팸 시그널 리스크 (unsourced — 보수 운영 원칙). 첫 2주는 수동 승인 발행만.
- 해시태그 30개 채우기·팔로우 어뷰징·DM 대량 발송 금지.
- 실사진(얼굴) 사용 금지 — 비노출 확정 (naming.md §2). 썸네일·프로필 전부 심볼/화면 캡처만.
- 사람인 척 금지 — AI 자동화 공장임을 bio·고정글에 명시 (투명성 = 컨셉의 핵심 자산).
- 코드·커밋에 브랜드명 금지 (공통 레포 정책).

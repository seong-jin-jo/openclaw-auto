# Playbook — 마케팅 실무 플레이북

**갱신: 2026-07-07** (WebSearch 13건 벤치마크, content-growth-marketer 리서치). 실행 결과는 [growth-log.md](./growth-log.md)에 기록.

## 잘나가는 SaaS가 실제로 크는 방법 (채널별 실사례)

### Build-in-public / 창업자 개인계정
- **Pieter Levels**: 10년간 X 팔로워 60만 축적하며 40+ 제품 공개 런칭. Photo AI 첫 주 $5.4K → 18개월 $132K MRR, 연 ~$3M. 구조: **유통(팔로워)을 먼저 쌓고 제품을 그 위에 얹음.**
- **Marc Lou**: 2025년 $1.03M, 28개 제품 전부 공개 런칭+매출 공개 — 단일 히트가 아니라 반복 런칭 서사.
- **Buffer**: 급여·매출 전면 공개 → 언론 헤드라인·백링크 자석화, 블로그 월 150만 방문. **투명성 = 무료 PR + SEO 복리.**
- **Tally**: 부트스트랩 $175K MRR(8명) — 성장 공개 블로깅 + 커뮤니티.

### 제품 자체가 유통 (워터마크/뱃지)
- **Opus Clip**: Free 워터마크 클립이 곧 광고 → 7개월 만에 5M 유저.
- **Tally**: "Made with Tally" 뱃지가 리드 생성기, 무료→Pro 전환 ~3%.

### Programmatic SEO
- **Zapier**: 통합조합 페이지 5만 개 → 월 5.8M+ 오가닉. **Canva**: 템플릿 페이지 2.2M+. 공통 구조 = **반복 템플릿 × 고유 데이터셋**. 얇은 복제 페이지는 실패.

### 오픈소스/커뮤니티-led
- **n8n**: fair-code 셀프호스트 무료 + 클라우드 유료 → 유저 20만+, ARR 5배, 주간 인바운드 리드 1,000+. **Postiz**: GitHub 리포 자체가 획득 퍼널.

### 숏폼 오가닉
- SaaS/앱 UGC 계정 사례 다수 (TripBFF 475.5M 누적 뷰 등). 단 **첫 리드까지 통상 60–90일** — 즉효 채널 아님.

### 창업자 LinkedIn (방향성만)
- 개인 프로필이 회사 페이지 대비 5–10x 도달 주장 — 출처가 대행사 블로그라 수치는 미채택, "개인계정 > 회사계정" 방향만 채택.

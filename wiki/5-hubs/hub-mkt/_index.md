# 마케팅 허브

R&R: 브랜드 사실을 지키며 채널별 콘텐츠를 기획·제작·발행하고 반응을 다음 실험에 연결한다. 사고방식: 구현된 채널 수가 아니라 실제 연결·발행 증거와 콘텐츠 품질을 분리해 판단한다.

마케팅·브랜드 지식의 정본. (신설 2026-07-07, 전면 정본화 2026-07-10, 컨셉 전환 2026-07-11, **워딩 전환 2026-07-16** — 계정 브랜드 = 콘텐츠 공장 **"OSMU 팩토리"**(구 비서 워딩 대체, 회장 직접 낙점)·타겟 = 사장님/자영업자 유지, [ADR-005](../../3-operations/decisions/005-brand-naming.md).)

**현재 마케팅 단계: 0차** — 운영자 직접 사용(도그푸딩), PMF 전. 원칙 = **제품 사용 자체가 마케팅이 되게 설계** (0차 안정화 리소스를 뺏지 않는다). 실행 시퀀스는 [gtm-plan.md](./gtm-plan.md).

## 하위모델·크론은 이 순서로 읽는다 (진입 지도)

1. **[naming.md](../../1-team-brand/naming.md)** — 이름의 유일한 진실원: 제품 **OSMU(오스무)** · 계정 **콘텐츠 공장 "OSMU 팩토리"**(사장님 done-for-you — 표시 이름 확정 2026-07-16, 하드코딩 가능). 다른 문서와 표기가 다르면 이 파일이 이긴다.
2. **[brand.md](../../1-team-brand/brand.md)** — 타겟·톤 시스템·금지어·필러 5. 모든 콘텐츠의 규율.
3. **[creative-briefs/](./creative-briefs/_index.md)** 콘텐츠를 생성한다면 여기서 시작한다.
4. **[hook-bank.md](./hook-bank.md)** — 후크 H-01~45 참조 뱅크 (raw/safer 라벨·{N} 실측 규칙).
5. **[content-calendar.md](./content-calendar.md)** — 시리즈 4개 + 첫 30일 캘린더.
6. **[channels/](./channels/_index.md)** 채널을 운영·설정한다면 여기서 시작한다.
7. **[design-system.md](../hub-design/design-system.md)** — 비주얼 만들 때 (팔레트·규격·AI 이미지 프롬프트 §7).

판단 불가 항목은 지어내지 말고 `⛔ 회수 필요`로 중단 — 각 문서의 에스컬레이션 규칙을 따른다.

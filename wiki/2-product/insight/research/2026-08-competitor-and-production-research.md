### 1.5 관찰

- **한국에는 발행·응대·성과를 묶은 구독형 도구가 조사 범위에서 안 보였습니다.** 그 자리를 인플루언서 대행과 광고 대행사가 차지하고 있습니다. 공개 자료 기준이라 못 찾았을 가능성은 남습니다.
- 성과를 다음 생성으로 되먹인다고 명시한 곳은 조사한 열한 곳 중 국내 한 곳이었습니다.
- 오가닉 소셜에서 그 고리를 닫은 제품은 열여덟 곳을 봤을 때 없었고, 닫은 두 곳은 이메일 카피 도구였습니다.
- 우리와 기능이 가장 가까운 곳은 Blotato, Simplified, Ocoya입니다.

## 2. 경쟁사 결과물 실물 분석 (sigmine 숏폼)

회장 제공 파일을 내려받아 확인했습니다.

| 항목 | 확인 내용 |
|---|---|
| 제작 도구 | 파일 메타데이터에 `Made with Remotion 4.0.435` |
| 규격 | 1080x1920, 30fps, 87초, h264 + AAC 스테레오 48kHz |
| 화면 | 상단 검정 띠 고정 타이틀(키워드만 노란색), 중앙 영상, 하단 자막 박스 |
| 영상 소재 | **AI 생성물이 아님.** 포켓몬 애니메이션, 미국 시트콤, 2D 일러스트, 옛날 인물 실사 영상이 섞임 |
| 컷 길이 | 0.4초 간격 프레임 두 장에서 장면이 통째로 교체됨. **컷이 1초 안팎** |
| 추정 구조 | 대본 생성 → 음성 합성 → 기존 동영상 조각 수집·엮기 → 자막과 타이틀 → 렌더 |

**함의:** 영상 생성 모델을 쓰지 않으므로 원가가 낮습니다. 편당 4,500~5,000원에 90~100편이 가능한 이유로 보입니다. 다만 소재가 타사 저작물입니다.

## 3. 중국 숏드라마 제작팀 프롬프트 구조

출처: 국내 서비스 toonkit이 자사 어뷰징 사고 후 공개한 역분석. 그 팀들은 다섯 시간에 수천만원어치 크레딧을 소모했습니다.

**목표가 품질 향상이 아니라 다시 뽑는 비용 최소화입니다.**

| 기법 | 내용 |
|---|---|
| 90퍼센트를 한 번에 | 완벽한 일관성을 시간과 비용으로 잡지 않고 한 번의 생성으로 90퍼센트를 잡습니다. 80편 시리즈 내내 프롬프트를 거의 안 바꿉니다 |
| 상대 비율 지시 | 형용사를 안 씁니다. 금속 광택 1.5, 피부 0.5, 천 0.3처럼 재질 간 비율로 적습니다. 절대값이 아니라 비율이라 여러 번 생성해도 관계가 유지됩니다. 프롬프트 예산의 5분의 1을 조명과 재질에 씁니다 |
| 캐릭터 시트 훼손 | 모델이 참고 이미지에서 얼굴을 그대로 가져오지 못하게 얼굴 부분을 의도적으로 훼손합니다 |
| 시작과 끝 상태 고정 | 참고 이미지를 안 넣고 각 인물의 시작 상태와 끝 상태를 한 줄씩 글로 적습니다. 컷 연결을 사람이 확인하는 병목이 사라집니다 |
| 다음 편 인계 | 프롬프트가 다음 에피소드로 이어질 내용까지 만들게 합니다. 첫 생성 한 번이면 다음 영상의 첫 장면과 첫 대사와 인물 상태 변화가 연쇄로 전달됩니다 |
| 더빙 중심 | 카메라와 구도에 프롬프트를 거의 안 씁니다. 음색과 성격은 인물에 고정된 상수, 상태와 어조는 컷마다 바뀌는 변수로 나눠 적습니다. 대사의 특정 단어 시점에 동작을 맞춥니다 |
| 대사 처리 | 원작 대사를 그대로 붙여 씁니다. 방영 중 시리즈의 미공개분을 만들고 있었습니다 |

## 5. 조립층 관련 근거

### 5.1 스킬이 요청에 실리는 방식

공식 문서 기준입니다. 시작할 때 시스템 프롬프트에 들어가는 것은 각 스킬의 이름과 설명뿐이고, 본문은 요청이 설명과 맞을 때 파일에서 읽혀 **메시지 배열 안의 도구 실행 결과**로 들어옵니다. 스크립트는 실행 결과만 들어오고 코드는 안 들어옵니다. **조합은 모델 서버가 아니라 클라이언트가 합니다.**

### 5.2 조립 규칙 근거

| 규칙 | 근거 |
|---|---|
| 금지 표현을 부정문으로 쓰지 않는다 | 공식 가이드가 하지 말라 대신 하라고 쓰라고 명시 |
| 긴 자료는 위, 지시는 아래 | 공식 가이드가 응답 품질 최대 30퍼센트 향상을 언급 |
| 중간에 둔 정보는 묻힌다 | 논문 |
| 태그로 격벽 | 공식 가이드 |
| 모순된 지시는 손해 | 다른 모델 공식 가이드 |
| 예시 세 개에서 다섯 개, 순서 고정 | 공식 권고와 순서 민감성 논문 |
| 단계적 사고는 수학 밖에서 이득 거의 없음 | 백여 편 메타분석 |
| 영상은 일곱 칸 | 영상 모델 공식 가이드 |

### 5.3 질문 설계 근거

되묻기는 언제·무엇을·어떻게로 나눠 다루고, 모호함을 낱말 문제로만 보면 엉뚱한 질문이 나갑니다. 보고 고르는 것이 기억해 쓰는 것보다 쉽고, 선택지가 너무 많으면 고르지 못합니다. 나눠서 모으면 이탈이 줍니다. 빈 입력창은 시작을 막습니다.

# 제품 빌드

OSMU와 Studio의 제품 정의, 구현 표면, 기능별 설명을 모은다. 시장 조사와 경쟁 판단은 고객·시장 이해에 둔다.

## 여기 있는 것

- [현재 상태](./current-state.md): 코드·산출물·상태 파일을 대조한 최신 스냅샷.
- [제품 비전](./vision.md): 제품 목표와 범위.
- [Studio](./studio.md): 생성·편집 제품 표면과 API.
- [Shorts Factory](./shorts-factory.md): 숏폼 제작 공장.
- [Marketing Hub 화면 지도](./marketing-hub-surface-map.md): 화면·API 표면 인벤토리.
- [GA4·Slack 계획](./plan-ga4-slack-central.md): 범위 결정과 구현 이력.
- [OSMU와 ZERO-ONE 사업 좌표](./사업좌표-OSMU와-ZERO-ONE.md): 내부 도그푸딩과 외부 판매의 연결.

## 여기서 시작하라

작업 재개는 [현재 상태](./current-state.md), 제품 판단은 [제품 비전](./vision.md)에서 시작한다.

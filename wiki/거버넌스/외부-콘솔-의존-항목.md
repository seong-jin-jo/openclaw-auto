# 외부 콘솔 의존 항목 대장

**왜 이 문서가 생겼나**: Supabase Redirect URL 이 빈칸인 것을 아무도 몰랐다.
배포 스모크가 서버 관점만 봐서 잡히지 않았고, 어디에도 "외부 콘솔에서 설정해야 하는 것"
목록이 없었다. 코드도 CI 도 이걸 못 본다. **사람이 콘솔에서 눌러야만 되는 것들의 정본이다.**

**규칙**: 외부 콘솔 설정에 의존하는 항목이 생기면 즉시 여기 한 줄 추가한다.
값은 절대 쓰지 않는다. 무엇을 어디서 설정해야 하는지만 쓴다.

| 항목 | 어디서 | 무엇을 | 상태 | 확인 방법 |
|---|---|---|---|---|
| Supabase Redirect URL | Supabase 대시보드 → Authentication → URL Configuration | 운영 도메인 `/login` 정확일치 한 줄 + `/login?**` 와일드카드 한 줄 | 2026-08-31 회장 등록 | 로그인 완주 여부 |
| Meta Threads 테스터 | developers.facebook.com 앱 콘솔 → App roles → Roles → Threads Testers | 연결할 계정을 테스터로 추가 후 **그 계정에서 초대 수락** | 미완, 회장 대기 | 연결 시 `threads_basic permission` 오류가 사라짐 |
| Meta App Review | 같은 앱 콘솔 → App Review | threads_basic 등 권한별 심사 제출 | 미제출. 준비 진행중 | 승인되면 테스터 등록 불필요 |
| 채널별 OAuth redirect URI | 각 플랫폼 개발자 콘솔 | 운영 도메인 콜백 경로를 **글자까지 일치**하게 등록 | 미확인 | 연결 시 Invalid redirect_uri 오류 부재 |
| Cloudflare Tunnel ingress | Cloudflare 대시보드 | hostname → 로컬 포트 매핑 | 동작중 | 토큰 방식이라 VM 디스크에 설정 없음. 서버에서 확인 불가 |
| GitHub Actions Secrets | 저장소 Settings → Secrets | 배포가 `.env.osmu` 로 렌더하는 값들 | 동작중 | 배포 스모크의 빌드 주입 검사 |

## 알려진 제약

- **Meta 콘솔 자동 조작 금지.** ADR-004. 2026-07-01 자동 운전으로 개발자 계정이
  플래그당한 실사고가 있다. 콘솔 작업은 계정주가 손으로 한다.
- `NEXT_PUBLIC_*` 값은 이미지 빌드 시각에 코드에 인라인된다.
  콘솔에서 값만 바꾸면 반영되지 않는다. 재빌드가 필요하다.
